Screen Flickering? Here's How to Fix It

Screen flickering is disorienting and often a sign of a driver issue, wrong refresh rate, or loose cable — rarely a serious hardware problem. This guide covers fixes for Windows, Mac, laptops, and external monitors.
Quick diagnostic: Open Task Manager (Ctrl+Shift+Esc). If Task Manager also flickers → it's a driver issue. If Task Manager is stable → an app is causing the problem.

Common Causes of Screen Flickering

Understanding what's causing your screen to flicker helps you apply the right fix:

  • Outdated or corrupted graphics drivers — Most common cause on Windows
  • Incorrect refresh rate — Monitor refresh rate not matching settings
  • Loose or damaged cable — HDMI, DisplayPort, or VGA connections
  • Power saving settings — Especially on laptops running on battery
  • App conflicts — Certain applications causing display issues
  • Hardware problems — Failing monitor or graphics card
  • Electromagnetic interference — Near other electronic devices

Fixes for Windows

Step 1 — Update Display Driver

Outdated graphics drivers are the #1 cause of screen flickering on Windows:

  • Right-click Start → Device Manager
  • Expand "Display adapters"
  • Right-click your GPU (NVIDIA, AMD, or Intel)
  • Select "Update driver" → "Search automatically for updated driver software"
  • If Windows doesn't find a newer driver, visit the manufacturer website:
    • NVIDIA: nvidia.com → Support → Download Drivers
    • AMD: amd.com → Support & Drivers
    • Intel: intel.com → Support → Download Drivers

Step 2 — Roll Back Driver (if flickering started after update)

If flickering began after a recent driver update, roll back to the previous version:

  • Device Manager → Display Adapters
  • Right-click GPU → Properties → Driver tab
  • Click "Roll Back Driver"
  • Select a reason and confirm
  • Restart your computer

Step 3 — Change Refresh Rate

Incorrect refresh rate can cause visible flickering:

  • Settings → System → Display → Advanced display settings
  • Click "Display adapter properties"
  • Go to "Monitor" tab
  • Under "Screen refresh rate," select your monitor's native rate (usually 60Hz or 144Hz)
  • Click Apply → OK

Check your monitor's manual or specs to find its native refresh rate.

Step 4 — Disable Hardware Acceleration in Apps

If flickering happens in specific applications (browsers, games):

  • Chrome: Settings → Advanced → System → Disable "Use hardware acceleration when available"
  • Firefox: Settings → Performance → Uncheck "Use recommended performance settings" → Disable Hardware Acceleration
  • General: Right-click app shortcut → Properties → Compatibility → Check "Disable full-screen optimizations"

Step 5 — Run SFC and DISM Scans

Corrupted system files can cause display issues. Run Windows built-in repair tools:

  • Open Command Prompt as Administrator
  • Type: sfc /scannow and press Enter
  • Wait for the scan to complete (may take 10-15 minutes)
  • If issues are found, run: DISM /Online /Cleanup-Image /RestoreHealth
  • Restart your computer

Step 6 — Check for Problematic Apps

Some apps conflict with display settings. Use a clean boot to identify:

  • Press Win+R → type msconfig
  • Go to Services tab → Check "Hide all Microsoft services"
  • Click "Disable all"
  • Go to Startup tab → Open Task Manager → Disable startup items
  • Restart and check if flickering persists
  • Enable services one by one to identify the culprit

Step 7 — Adjust Power Settings

Power settings can affect display behavior:

  • Settings → System → Power
  • Click "Additional power settings"
  • Select "High performance" plan
  • Click "Change plan settings" → "Change advanced power settings"
  • Expand "Display" → "Enable adaptive brightness" → Turn OFF for both battery and plugged in

Step 8 — Check Cables and Connections

Physical connections are often overlooked:

  • Unplug and replug your monitor cable
  • Try a different HDMI/DisplayPort port on your GPU
  • Test with a different cable if possible
  • Ensure cable is fully seated in both monitor and PC
  • For laptops, try closing and opening the lid

Fixes for Mac

Step 1 — Disable True Tone

True Tone can sometimes cause perceived flickering:

  • System Settings → Displays
  • Turn OFF "True Tone"
  • Also check "Night Shift" in System Settings → Displays → Night Shift
  • Turn OFF or adjust Night Shift schedule

Step 2 — Reset SMC (Intel Macs)

The System Management Controller controls display power:

  • Shut down your Mac
  • Press Shift+Control+Option+Power and hold for 10 seconds
  • Release and press Power to turn on

Step 3 — Lower Refresh Rate (ProMotion Displays)

ProMotion displays on some MacBooks can have compatibility issues:

  • System Settings → Displays
  • Select your display
  • Try selecting 60Hz instead of ProMotion (up to 120Hz)
  • Check if flickering stops

Step 4 — Reset NVRAM

NVRAM stores display-related settings:

  • Shut down Mac
  • Press Power → immediately hold Option+Command+P+R
  • Hold for 20 seconds until you hear startup sound twice
  • Release and let Mac boot

Step 5 — Check External Monitor Connections

For external monitors connected to Mac:

  • Try different cables (HDMI, DisplayPort, USB-C)
  • Reset monitor to factory settings
  • Update monitor firmware if available
  • Try a different port on the Mac

For External Monitors

Check or Replace the Cable

A damaged or loose HDMI/DisplayPort cable is the #1 cause of external monitor flickering:

  • Try a different cable — this fixes the issue most often
  • Avoid cables over 2 meters for 4K/144Hz displays
  • Ensure cables are rated for your resolution/refresh rate
  • Check cable ends for visible damage

Monitor Settings

Adjust your monitor's internal settings:

  • Access monitor menu (usually buttons on the monitor)
  • Reset to factory defaults
  • Check for "Overdrive" or "Response Time" setting — too high can cause flicker
  • Ensure "FreeSync" or "G-Sync" is properly enabled if using adaptive sync

Test with Another Device

Determine if the issue is the monitor or your computer:

  • Connect the monitor to another computer or laptop
  • If flickering persists on another device, the monitor likely has a hardware issue
  • If it works on another device, the issue is your computer's graphics output

Laptop-Specific Issues

Screen Flickering on Battery

If flickering only happens when running on battery:

  • Settings → System → Power → Screen brightness
  • Disable "Change brightness automatically when lighting changes"
  • Check Intel HD Graphics control panel: Right-click desktop → Graphics Options → Power → On Battery → Set to "Maximum Performance"
  • Try keeping laptop plugged in to see if issue persists

Laptop Screen Flickering

If your built-in laptop display flickers:

  • Update laptop-specific graphics drivers from manufacturer website (Dell, HP, Lenovo, etc.)
  • Check BIOS for display settings updates
  • Try external monitor — if external works, the laptop panel may be failing
  • Check if a certain angle triggers the flicker (pressure on screen edge may indicate loose connection)

Specific Display Problems

Flickering Only in Games

If flickering is game-specific:

  • Update game to latest version
  • Update GPU drivers
  • Disable V-Sync or enable it (try both)
  • Lower graphics settings to test
  • Check for known issues with specific game and your GPU

Flickering in Full Screen

If flickering occurs in full-screen mode but not windowed:

  • Disable hardware acceleration in the application
  • Run games in borderless windowed mode instead of fullscreen
  • Update Windows and graphics drivers

Frequently Asked Questions

Why does my screen flicker only when on battery?

This is a power-saving feature. In Windows: Settings → System → Power → Screen brightness → Disable "Change brightness automatically when lighting changes." Also check Intel HD Graphics panel settings and set power profile to maximum performance on battery.

Is screen flickering dangerous?

Generally no — it's usually a software or cable issue. However, if accompanied by strange noises, burning smell, or the screen shows unusual patterns, turn off the monitor immediately and have it inspected by a professional.

Can a bad HDMI cable cause flickering?

Yes, a damaged or low-quality HDMI cable is one of the most common causes of monitor flickering. Try replacing with a certified High-Speed HDMI cable. For 4K at 60Hz or higher, use HDMI 2.0/2.1 cables.

Why does my screen flicker when I move the mouse?

This could indicate a failing graphics card, loose monitor cable, or power supply issues. Try updating drivers and checking cable connections. If it persists, have your hardware tested.

Can screen flickering be fixed without replacing hardware?

Yes, in most cases flickering is a software issue — driver updates, refresh rate changes, or cable replacements fix it. Hardware failure (failing monitor panel or GPU) would require component replacement.

Does screen flickering mean my GPU is dying?

Not necessarily — flickering is more often caused by outdated drivers or cable issues. However, if accompanied by graphical artifacts, crashes during graphics-heavy tasks, or other symptoms, your GPU may be failing. Test with a different GPU if possible.
