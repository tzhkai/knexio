Discord Not Responding?

Fix Discord freezing, crashes, and hangs

Quick Fix: Press Ctrl+Shift+Esc (Windows) or Cmd+Option+Esc (Mac) to open Task Manager, find Discord, click "End Task", then reopen Discord.

Why Does Discord Stop Responding?

Discord freezing or not responding is a common issue that can occur for several reasons. Understanding what causes the problem helps you apply the right solution.

  • Outdated Discord version — Using an older version may contain bugs that cause freezing
  • Corrupted cache — Discord stores temporary data that can become corrupted over time
  • Hardware acceleration conflicts — Discord uses your GPU for rendering, which can conflict with other apps or drivers
  • Insufficient system resources — Low memory or high CPU usage from other programs
  • Conflicting software — Antivirus programs, overlays, or screen recording software
  • Corrupted installation — Discord files may have been partially deleted or damaged

1. Force Close and Restart Discord

Press Ctrl+Shift+Esc (Windows) or Cmd+Option+Esc (Mac) to open Task Manager. Find Discord in the list, right-click, and select "End Task". Then relaunch Discord.

On Android: Go to Settings → Apps → Discord → Force Stop. Then reopen the app.

On iOS: Swipe up from the bottom of the screen to close Discord, then tap the Discord icon to relaunch.

2. Clear Discord Cache

Discord stores cached data that can become corrupted and cause freezing issues. Clearing this data often fixes the problem.

On Windows:

  • Close Discord completely (make sure it's not running in the background)
  • Press Win+R, type %AppData% and press Enter
  • Locate the "discord" folder and delete it
  • Also check %LocalAppData% for any Discord folders and delete them
  • Restart Discord — it will recreate the folders with fresh data

On Mac:

  • Close Discord completely
  • Open Finder, press Cmd+Shift+G, and type ~/Library/Application Support
  • Delete the "Discord" folder
  • Also go to ~/Library/Caches and delete any Discord folders
  • Restart Discord

3. Update Discord

Discord regularly releases updates that fix bugs and improve stability. Make sure you're running the latest version.

On Desktop:

  • Click the gear icon (⚙️) in the bottom-left corner
  • Select "Check for Updates" in the left sidebar
  • If an update is available, Discord will download and install it automatically
  • Alternatively, download the latest version from discord.com

On Mobile:

  • Open App Store (iOS) or Google Play Store (Android)
  • Search for "Discord"
  • If an update is available, tap "Update"

4. Disable Hardware Acceleration

This is one of the most effective fixes for Discord freezing issues. Hardware Acceleration uses your GPU to render Discord, but it can conflict with other applications or drivers.

  • Click the gear icon (⚙️) in the bottom-left of Discord
  • Go to "Advanced" in the left sidebar
  • Toggle OFF "Hardware Acceleration"
  • Restart Discord for the change to take effect

Disabling hardware acceleration forces Discord to use software rendering, which resolves most freezing issues, especially on laptops with integrated graphics cards.

5. Run Discord as Administrator

Sometimes Discord needs elevated permissions to function properly, especially on Windows.

  • Right-click the Discord shortcut or .exe file
  • Select "Run as administrator"
  • This can resolve permission-related issues that cause Discord to freeze

To make this permanent: Right-click Discord shortcut → Properties → Compatibility → Check "Run this program as administrator"

6. Disable Discord Overlay

The in-game overlay can cause conflicts with certain games and applications.

  • Click the gear icon (⚙️) → "Activity Settings"
  • Toggle OFF "Enable in-game overlay"
  • Alternatively, press Shift+Ctrl+G (Windows) to quickly toggle the overlay

7. Check for Conflicting Software

Several types of software can conflict with Discord:

  • Antivirus/Firewall — Temporarily disable your antivirus to see if that's causing the freeze. If so, add Discord to the exceptions list.
  • Screen recording/OBS — Close OBS Studio or other screen recording software
  • VPN software — Some VPNs can cause Discord to freeze; try disabling temporarily
  • RGB software — Corsair iCUE, Razer Synapse, and other RGB control software can interfere

8. Reinstall Discord

If the above steps don't work, a clean reinstall often fixes corrupted installation issues.

On Windows:

  • Go to Settings → Apps → Find Discord → Uninstall
  • Also delete the Discord folders in %AppData% and %LocalAppData%
  • Download the latest version from discord.com
  • Install and log in

On Mac:

  • Drag Discord from Applications to Trash
  • Delete Discord folders from ~/Library/Application Support and ~/Library/Caches
  • Download fresh installer from discord.com

On Mobile:

  • Long-press Discord → Remove App (iOS) or Uninstall (Android)
  • Reinstall from the App Store or Play Store

9. Check System Resources

Discord freezing can be caused by insufficient system resources. Check if your computer is running low on memory or CPU.

On Windows:

  • Open Task Manager (Ctrl+Shift+Esc)
  • Look at CPU and Memory usage
  • Close unnecessary programs to free up resources
  • Disable startup programs that run in the background

If you have less than 4GB of RAM available when Discord is running, consider upgrading your RAM or closing more applications.

10. Repair Discord (Windows)

Windows has a built-in repair feature that can fix corrupted application files.

  • Go to Settings → Apps → Installed Apps
  • Find Discord and click the three dots
  • Select "Modify" → "Repair"
  • Wait for the repair process to complete
  • Restart Discord

Specific Discord Error Messages and Fixes

"Discord not responding" after joining a call

If Discord freezes specifically when joining a voice or video call:

  • Try disabling hardware acceleration (step 4)
  • Reduce your video quality in User Settings → Voice & Video
  • Try using the web version of Discord instead
  • Disable any camera or screen share that's not needed

Discord freezes on startup

If Discord freezes at the loading screen:

  • Delete the Discord cache folders (step 2)
  • Try starting Discord in Safe Mode by holding Ctrl while clicking the icon
  • Check if a VPN is running and disable it
  • Try using the browser version at discord.com/app

Discord crashes when typing

If Discord freezes when you're typing a message:

  • Try disabling "Use data to improve Discord" in Settings → Privacy & Safety
  • Clear your text chat history in the server (not recommended for important conversations)
  • Try a different keyboard input method

Frequently Asked Questions

Why does Discord keep freezing?

Common causes: outdated app, corrupted cache, hardware acceleration conflicts, or insufficient system resources. Start by updating Discord and clearing cache.

Does disabling hardware acceleration help?

Yes, this is one of the most effective fixes for Discord freezing issues on Windows and Mac. It forces Discord to use CPU rendering instead of GPU, which resolves most display-related freezes.

Will I lose my messages if I reinstall Discord?

No, your messages are stored on Discord's servers, not locally. Reinstalling Discord won't delete your chat history. However, server-specific custom emoji and some settings may need to be reconfigured.

Why does Discord freeze on my laptop but not desktop?

Laptops often have integrated graphics cards that have less processing power. Additionally, laptop power management settings can limit resources. Try disabling hardware acceleration and checking your power plan settings.

Can a VPN cause Discord to freeze?

Yes, some VPNs can cause Discord freezing, especially if the VPN server is slow or experiencing issues. Try disabling your VPN temporarily to see if that resolves the issue.

What's the difference between Discord freezing and crashing?

Freezing means the application becomes unresponsive but doesn't close. Crashing means the application closes unexpectedly. Both issues share similar causes, but freezing is often a resource or software conflict issue while crashing can indicate more serious problems.

Summary

Discord freezing issues are almost always fixable. Start with the quick fix (force close and restart), then try disabling hardware acceleration and clearing cache. These two steps resolve the majority of freezing issues. If problems persist, reinstall Discord completely.

If you continue experiencing freezing after trying all these steps, consider checking Discord's status page or submitting a bug report through the app (Settings → Help → Submit Feedback).
