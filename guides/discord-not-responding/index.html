Discord Not Responding?

Fix Discord freezing, crashes, and hangs

Ad space

1. Force Close and Restart Discord

Press Ctrl+Shift+Esc (Windows) or Cmd+Option+Esc (Mac) to open Task Manager. Find Discord in the list, right-click, and select "End Task". Then relaunch Discord.

2. Clear Discord Cache

Close Discord completely. Press Win+R, type %AppData% and press Enter. Delete the "discord" folder. Also check %LocalAppData% for Discord folders. Restart Discord.

3. Update Discord

Click the gear icon → "Check for Updates". If an update is available, install it. Outdated versions often cause freezing issues.

4. Disable Hardware Acceleration

Settings → Advanced → Turn off "Hardware Acceleration". This forces Discord to use software rendering, which fixes many freeze issues.

5. Reinstall Discord

Uninstall Discord from Settings → Apps. Download the latest version from discord.com and reinstall. This often fixes corrupted installation issues.

Frequently Asked Questions

Why does Discord keep freezing?

Common causes: outdated app, corrupted cache, hardware acceleration conflicts, or insufficient system resources.

Does disabling hardware acceleration help?

Yes, this is one of the most effective fixes for Discord freezing issues on Windows and Mac.
