How to Clear Cache

Step-by-step for Chrome, Firefox, Safari, and Edge

Ad space

Google Chrome

Press Ctrl+Shift+Delete (Windows) or Cmd+Shift+Delete (Mac).

  • Set time range to "All time"
  • Check "Cached images and files"
  • Click Clear data
💡 Shortcut: Type chrome://settings/clearBrowserData in the address bar.

Mozilla Firefox

Press Ctrl+Shift+Delete (Windows) or Cmd+Shift+Delete (Mac).

  • Set time range to "Everything"
  • Check "Cache"
  • Click OK

Safari (Mac)

  • Go to Safari → Settings → Advanced
  • Enable "Show Develop menu in menu bar"
  • Click Develop → Empty Caches
  • Or press Cmd+Option+E

Microsoft Edge

Press Ctrl+Shift+Delete.

  • Select "Cached images and files"
  • Choose time range
  • Click Clear now

Mobile (iOS / Android)

Chrome on Android: Menu → Settings → Privacy → Clear browsing data → Cached images and files.

Safari on iPhone: Settings → Safari → Clear History and Website Data.

Frequently Asked Questions

Will clearing cache delete my passwords?

No. Clearing cache only removes temporary files. Passwords are stored separately — only deleted if you specifically check "Passwords".

How often should I clear cache?

When pages look outdated, load slowly, or you see login issues. Most users clear cache every few months.

What's the difference between cache and cookies?

Cache stores page files (images, scripts) for faster loading. Cookies store login sessions and preferences.
