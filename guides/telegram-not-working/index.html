Telegram Not Working? How to Fix Common Telegram Problems

Telegram is known for reliability, but sometimes connection issues occur. Here's how to fix common problems on all platforms.

Common Causes of Telegram Problems

  • Network connectivity issues: Slow or unstable internet
  • Regional blocking: Telegram is restricted in some countries
  • Outdated app: Older versions may have bugs
  • Permission issues: Missing notifications, camera, or microphone permissions
  • Account issues: Verification code problems or account lock
  • Server issues: Check for Telegram server outages

Fix 1: Telegram Not Connecting

If Telegram won't connect or messages won't send:

  1. Check your internet connection by loading other websites or apps
  2. Toggle airplane mode on and off to reset your network
  3. Try using a VPN if Telegram is restricted in your region (use a server in a country where Telegram is available)
  4. Switch between Wi-Fi and mobile data
  5. Check Telegram server status online at downdetector.com/telegram
  6. Restart your device
  7. Clear Telegram cache (see below)

Fix 2: Messages Not Sending

If messages show one check mark and won't deliver:

  1. Check if you're connected (look for connection status in settings)
  2. Check if the recipient has blocked you (you won't see a specific indicator, but messages will stay at one check)
  3. Verify you're not in a region blocking Telegram
  4. Clear Telegram cache: Settings → Data and Storage → Storage Usage → Clear Cache
  5. Log out of Telegram and log back in
  6. Try sending a message to a different contact

Fix 3: Notifications Not Working

  1. Check that Telegram notifications are enabled in device settings
  2. Check if Do Not Disturb or Focus mode is on
  3. Go to Telegram Settings → Notifications → ensure notifications are enabled
  4. On Android: Settings → Apps → Telegram → Notifications → make sure they're allowed
  5. On iOS: Settings → Notifications → Telegram → Enable notifications
  6. Check battery optimization settings (battery savers may block notifications)

Fix 4: Telegram Crashes or Freezes

  1. Update to the latest Telegram version
  2. Restart your device
  3. Clear app data: Settings → Data and Storage → Storage Usage → Clear Cache
  4. On Android, if crashes continue, try Settings → Apps → Telegram → Storage → Clear Data
  5. On iOS, delete and reinstall the app
  6. Check available storage space

Fix 5: Audio/Video Call Troubleshooting

Telegram supports voice and video calls. Here's how to fix issues:

Voice Calls Not Working

  1. Check your internet connection (Telegram calls need stable connection)
  2. Go to Settings → Calls → ensure "Telegram Calls" is enabled
  3. Check microphone permissions in your device settings
  4. Switch between Wi-Fi and mobile data
  5. Try using headphones to test
  6. Ensure the recipient also has Telegram calls enabled

Video Calls Not Working

  1. Tap the camera icon in a call to enable video
  2. Ensure camera permissions are granted to Telegram
  3. Close other apps using the camera
  4. Check your internet speed (video calls need more bandwidth, at least 1 Mbps)
  5. Try switching to audio call and back to video
  6. Make sure both parties have the latest Telegram version

Poor Call Quality

  • Switch from Wi-Fi to mobile data if connection is unstable
  • Close other bandwidth-heavy applications
  • Use headphones for better audio
  • Move to an area with better signal
  • Turn off video if connection is poor and use voice only

Fix 6: Connection & Firewall Issues

Telegram may not connect due to network restrictions:

Region Blocking

Telegram is blocked in some countries (e.g., Iran, China, Pakistan, Nigeria). To use Telegram:

  1. Use a VPN service to bypass restrictions
  2. Connect to a server in a country where Telegram is available
  3. Use Telegram's built-in proxy: Settings → Data and Storage → Proxy → Add Proxy
  4. Some Telegram MTProto proxies are publicly available — search for free proxy addresses

Firewall Configuration

If Telegram is blocked by your network:

  1. Try using a VPN to test if firewall is the issue
  2. Contact network administrator to allow Telegram domains
  3. Telegram uses ports: TCP 443, 80, 5222, 5223 for connections
  4. If on corporate network, contact IT for access

Mobile Data Issues

  • Toggle airplane mode on/off to reset network
  • Check if mobile data is enabled
  • Verify you haven't exceeded your data limit
  • Try switching between Wi-Fi and mobile data
  • Check if your carrier blocks certain ports

Fix 7: Login Problems

Can't Receive Verification Code

  1. Ensure your phone can receive SMS
  2. Check if your number is correct with country code (e.g., +1 for US, +44 for UK)
  3. Try "Call Me" option instead of SMS
  4. Wait a few minutes and try again (rate limiting applies)
  5. Ensure you're not in airplane mode
  6. Try a different phone number if possible

Account Locked

If Telegram locks your account:

  1. Wait 24-48 hours for automatic unlock
  2. Use the "Forgot password?" flow if you set up 2FA with a recovery email
  3. Contact Telegram support if the issue persists
  4. Try logging in from a different device
  5. Don't attempt to register multiple times quickly — this triggers blocks

Two-Factor Authentication

If you enabled 2FA and forgot your password:

  1. Enter your phone number
  2. Click "Forgot password?" when prompted
  3. Telegram will email you a recovery link (if you set up recovery email)
  4. Check your email (including spam folder) for the recovery link
  5. Create a new password

Fix 8: Update Procedures

Update on Mobile

  1. iOS: Open App Store → Search Telegram → Update
  2. Android: Open Play Store → Search Telegram → Update
  3. Enable auto-updates to get future updates automatically
  4. Always update to the latest version for security and bug fixes

Update on Desktop

  1. Open Telegram Desktop
  2. Click the three lines menu → Settings → Check for updates
  3. Or download latest from telegram.org/dl

Update Not Working

If updates fail:

  1. Delete the old version first
  2. Clear app data/cache
  3. Download fresh installer
  4. Reinstall
  5. Ensure you have sufficient storage space

Fix 9: Cache Clearing Steps

Clearing cache frees up storage and resolves issues:

Clear Cache on Android

  1. Open Telegram → Settings → Data and Storage
  2. Tap "Storage Usage"
  3. Tap "Clear Cache" (this removes temporary files but keeps messages)
  4. Or: Settings → Apps → Telegram → Storage → Clear Cache

Clear Cache on iOS

  1. Open Telegram → Settings → Data and Storage
  2. Tap "Storage Usage"
  3. Tap "Clear Telegram Cache"
  4. Note: iOS doesn't allow manual cache clearing per-app; deleting and reinstalling clears cache

Clear Cache on Desktop

  1. Open Telegram Desktop
  2. Settings → Advanced → Clear Local Data
  3. Or navigate to Telegram data folder and delete Cache folder
  4. On Windows: %AppData%\Telegram Desktop
  5. On Mac: ~/Library/Application Support/Telegram Desktop
  6. Restart Telegram
Tip: Use Telegram Web (web.telegram.org) as a backup when the mobile app has issues.

Frequently Asked Questions

Why does Telegram show "typing" but messages don't send?

This can happen when your connection is unstable. Try switching between Wi-Fi and mobile data, or restart the app.

Can I use Telegram on multiple devices?

Yes, Telegram supports multi-device usage. You can be logged in on phone, tablet, and desktop simultaneously.

Why does Telegram need so many permissions?

Telegram needs camera and microphone for calls, contacts to find friends, and storage to send files. You can manage permissions in your device settings.

How do I backup my Telegram chats?

Go to Settings → Chat Settings → Chat Backup → Enable. On iOS, it uses iCloud; on Android, it uses Google Drive or local storage.

Is Telegram safe and private?

Telegram offers end-to-end encryption for secret chats, but regular chats use server-client encryption. For maximum privacy, use "Secret Chat" feature.
