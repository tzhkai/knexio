How to Fix "App Not Responding" on Windows

If an app freezes or shows the message "Not Responding" on Windows, it can interrupt your work and cause data loss. This guide explains why it happens and how to fix it safely.

Why Apps Stop Responding on Windows

An unresponsive app usually means Windows cannot process its requests fast enough. Common causes include:

  • High CPU or RAM usage from background processes
  • Corrupted application or system files
  • Outdated software or Windows version
  • Driver conflicts or hardware issues
  • Malware consuming system resources
  • Registry corruption affecting app execution
  • Compatibility issues with Windows 10/11 updates
  • Insufficient virtual memory/pagefile settings

Step-by-Step Fixes

Step 1 — Force Close the App

  • Press Ctrl + Shift + Esc to open Task Manager
  • Find the unresponsive app in the list
  • Right-click → End Task

Advanced Command Line Method (PowerShell/CMD):

  • Open PowerShell/CMD as Administrator
  • List processes: tasklist | findstr "appname"
  • Force kill: taskkill /f /im "appname.exe"
  • Kill by PID: taskkill /f /pid [PID]

Step 2 — Restart Your Computer

Restarting clears memory, stops background conflicts, and resets temporary system states that may be causing the freeze.

Command Line Restart Options:

  • Normal restart: shutdown /r /t 0
  • Restart with reason: shutdown /r /t 0 /c "App not responding fix"
  • Force close apps and restart: shutdown /r /f /t 0

Step 3 — Free Up System Resources

  • Open Task Manager → check CPU and RAM usage
  • Close unused background apps
  • Disable unnecessary startup programs via Task Manager → Startup tab

Command Line Resource Management:

  • Check RAM usage: wmic OS get FreePhysicalMemory,TotalVisibleMemorySize /Value
  • Check CPU usage: wmic cpu get loadpercentage
  • List startup programs: wmic startup get caption,command
  • Disable specific startup via Registry: reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "ProgramName" /f

Step 4 — Boot into Safe Mode (Windows 10/11)

If app freezes on startup or system is unstable:

  • Method 1: Hold Shift + click Restart from login screen → Troubleshoot → Advanced Options → Startup Settings → Restart → Press 4 (Safe Mode) or 5 (Safe Mode with Networking)
  • Method 2: Force shutdown 3 times during boot → Recovery mode → Advanced options → Startup Settings
  • Command Line: Open CMD as Admin → bcdedit /set {default} safeboot minimal → Restart (use bcdedit /deletevalue {default} safeboot to disable)

Step 5 — Update Windows and App

Go to Settings → Windows Update and install any pending updates. Also update the specific app that keeps freezing.

Command Line Update Methods:

  • Check for updates: usoclient StartScan (Windows 10+)
  • Check update history: wmic qfe list
  • Install specific KB: wusa.exe [update].msu /quiet /norestart
  • Force Windows Store app updates: wsreset -i

Step 6 — Update Device Drivers

Outdated GPU or chipset drivers often cause crashes. Open Device Manager, right-click devices with a warning icon, and select Update driver.

Command Line Driver Management:

  • List all drivers: driverquery /v
  • Export driver list: driverquery /fo csv > drivers.csv
  • Check for problematic drivers: pnputil /enum-drivers
  • Rollback driver (if BSOD after update): pnputil /rollback-driver "DeviceID"

Step 7 — Registry Fixes for App Performance

Warning: Backup registry before making changes (regedit → File → Export)

  • Increase timeout for hung programs: reg add "HKCU\Control Panel\Desktop" /v HungAppTimeout /t REG_SZ /d 5000 /f
  • Disable visual effects for better performance: reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\VisualEffects" /v VisualFXSetting /t REG_DWORD /d 2 /f
  • Disable Windows Defender real-time scanning during heavy tasks: reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender" /v DisableAntiSpyware /t REG_DWORD /d 1 /f
  • Reset Windows search index if slowing apps: reg add "HKLM\SOFTWARE\Microsoft\Windows Search" /v SetupCompletedSuccessfully /t REG_DWORD /d 0 /f

Step 8 — System File and Component Repair

Use Windows built-in repair tools in Command Prompt (Admin):

  • SFC Scan: sfc /scannow (scans and repairs system files)
  • DISM Repair: DISM /Online /Cleanup-Image /RestoreHealth
  • Check Windows Store apps: Get-AppxPackage -AllUsers | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml"}
  • Reset Windows performance counters: lodctr /R
  • Rebuild icon cache: Delete %localappdata%\IconCache.db and restart explorer.exe

Step 9 — Scan for Malware

Malware can consume system resources silently. Run a full scan with Windows Security (built-in) or a trusted antivirus.

Command Line Malware Scanning:

  • Windows Defender quick scan: MpCmdRun.exe -Scan -ScanType 1
  • Full system scan: MpCmdRun.exe -Scan -ScanType 2
  • Update Defender definitions: MpCmdRun.exe -SignatureUpdate
  • Check Defender status: Get-MpComputerStatus (PowerShell)

Step 10 — Repair or Reinstall the App

Go to Settings → Apps → Installed Apps, find the problematic app, click the three-dot menu and choose Repair if available, or uninstall and reinstall a fresh copy.

PowerShell App Management:

  • List installed apps: Get-AppxPackage (Store apps) or Get-WmiObject -Class Win32_Product (traditional apps)
  • Uninstall Store app: Remove-AppxPackage PackageFullName
  • Reinstall all Store apps: Get-AppxPackage -AllUsers | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml" -ErrorAction SilentlyContinue}

Step 11 — Windows 10/11 Specific Troubleshooting

Windows 10 specific fixes:

  • Disable Timeline feature: reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\System" /v PublishUserActivities /t REG_DWORD /d 0 /f
  • Fix Windows 10 search slowdown: Get-AppxPackage -Name Microsoft.Windows.Cortana | Remove-AppxPackage
  • Disable telemetry: reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection" /v AllowTelemetry /t REG_DWORD /d 0 /f

Windows 11 specific fixes:

  • Disable Widgets panel: reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v TaskbarDa /t REG_DWORD /d 0 /f
  • Fix Windows 11 context menu slowdown: reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
  • Disable Snap Layouts: reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v SnapAssist /t REG_DWORD /d 0 /f

Step 12 — When to Reset or Reinstall Windows

Consider resetting Windows when:

  • Multiple apps freeze consistently despite all fixes
  • System-wide slowdowns affecting all applications
  • Corrupted system files that SFC/DISM cannot repair
  • Persistent blue screens (BSOD) alongside app freezes
  • Suspected deep-rooted malware infections

Reset Options (Windows 10/11):

  • Keep my files: Settings → System → Recovery → Reset this PC → Keep my files
  • Remove everything: Complete clean install (backup important data first)
  • Command Line Reset: systemreset --factoryreset (Windows 10) or systemreset -cleanpc (Windows 11)
  • Fresh Start (Windows 10): Security → Device performance & health → Fresh start

Advanced Reinstall Methods:

  • Create Windows installation media via Microsoft's Media Creation Tool
  • Clean install from USB (recommended for persistent issues)
  • Use Windows Recovery Environment (WinRE) for advanced repair

Frequently Asked Questions

Why does an app keep saying "Not Responding" on Windows 11 specifically?

Windows 11 has stricter memory management and security features. Apps may freeze due to incompatible drivers, Windows Defender real-time scanning, or conflicts with new UI components like Widgets. Disable experimental features and ensure drivers are Windows 11 certified.

How to fix app freezing only on Windows 10 22H2/23H2?

Recent Windows 10 updates may have compatibility issues. Try: 1) Disable optional updates, 2) Use compatibility mode (right-click app → Properties → Compatibility), 3) Disable Windows Security temporarily, 4) Check for known issues on Microsoft's support site.

Is it safe to force close an unresponsive app using Command Prompt?

Yes, taskkill /f /im is safe for terminating processes. However, system processes (svchost.exe, explorer.exe, etc.) should not be terminated unless you know what they do. Always save work before force closing.

Can registry edits really fix app freezing issues?

Yes, registry tweaks can resolve performance-related freezing. Common fixes include increasing timeouts, disabling visual effects, and optimizing memory management. Always backup the registry before making changes.

How do I prevent apps from freezing in the future on Windows 10/11?

1) Keep Windows and drivers updated, 2) Use SSD for system drive, 3) Maintain 20%+ free disk space, 4) Regular malware scans, 5) Disable unnecessary startup programs, 6) Monitor temperatures, 7) Use Windows built-in performance troubleshooter, 8) Consider upgrading RAM if consistently above 80% usage.

When should I do a complete Windows reinstall vs. reset?

Reset: When system files are corrupted but you want to keep personal files. Reinstall: When facing persistent hardware-level issues, deep malware infections, or migrating to new hardware. Clean install is best for maximum stability.

Conclusion

Most "App Not Responding" issues on Windows 10/11 can be resolved through systematic troubleshooting: force closing unresponsive apps, checking system resources, updating drivers and Windows, repairing system files, and applying registry optimizations. For persistent problems, booting into Safe Mode helps isolate the cause. When all else fails, Windows reset or clean reinstallation provides a fresh start. Regular maintenance including disk cleanup, malware scans, and keeping software updated prevents most freezing issues.
