1. Quick Fixes to Try First

Before diving into detailed troubleshooting

  1. Restart Chrome completely — close all windows and open Chrome again
  2. Restart your computer — this clears memory and resets background processes
  3. Update Chrome — Menu → Help → About Google Chrome
  4. Check your internet connection — try loading other websites to confirm connectivity
Tip: If Chrome works fine in incognito mode, the issue is likely caused by an extension, cookie, or cached file.

2. Chrome Keeps Crashing

Chrome crashes can happen due to corrupted data, conflicting extensions, outdated software, or system resource issues. Here's a systematic approach:

Step 1: Update Chrome

  1. Open Chrome and click the three-dot menu (top right)
  2. Go to Help → About Google Chrome
  3. Chrome will automatically check for and install updates
  4. Click Relaunch after the update installs

Step 2: Clear Cache and Cookies

Clear browsing data

  1. Press Ctrl + Shift + Delete (Windows) or Cmd + Shift + Delete (Mac)
  2. Set the time range to All time
  3. Check Cookies and Cached images and files
  4. Click Clear data

Step 3: Disable Extensions

  1. Type chrome://extensions in the address bar
  2. Toggle off each extension one by one to identify problematic ones
  3. Common culprits: ad blockers, VPN extensions, shopping plugins, toolbar add-ons
  4. Remove any extensions you don't need or trust

Step 4: Reset Chrome Settings

  1. Go to Settings → Reset and clean up
  2. Click Restore settings to their original defaults
  3. Confirm by clicking Reset settings
  4. This won't delete your bookmarks or saved passwords

Step 5: Scan for Malware

Malware can cause Chrome to crash or behave unexpectedly:

  1. Download the Chrome Cleanup Tool from Google (search for it on google.com/chrome/cleanup)
  2. Run the tool to detect and remove software
  3. Also run a full scan with your antivirus software

3. Chrome Won't Open at All

If Chrome fails to launch, try these solutions in order:

Method 1: End Chrome Processes

  1. Press Ctrl + Shift + Esc to open Task Manager
  2. Find all Chrome processes (chrome.exe)
  3. Click each one and select End task
  4. Try launching Chrome again

Method 2: Launch with Flags

  1. Right-click your Chrome shortcut
  2. Select Properties
  3. Add --disable-gpu --disable-extensions to the end of the Target field
  4. Launch Chrome using this modified shortcut

Method 3: Create New User Profile

  1. Close Chrome completely
  2. Press Win + R and type %LOCALAPPDATA%\Google\Chrome\User Data
  3. Rename the Default folder to Default.old
  4. Launch Chrome — it will create a fresh profile
  5. If this fixes the issue, you can migrate bookmarks from the old profile

Method 4: Reinstall Chrome

Complete reinstall

  1. Uninstall Chrome from Settings → Apps → Installed apps
  2. Also delete the Chrome folders in %LOCALAPPDATA%\Google\Chrome and %PROGRAMFILES%\Google\Chrome
  3. Download the latest Chrome from google.com/chrome
  4. Install and sign in to restore your data
Warning: Uninstalling Chrome will remove bookmarks, saved passwords, and settings. Sync your data to your Google account first, or manually export bookmarks before reinstalling.

4. Chrome is Slow or Laggy

Chrome can become sluggish due to excessive tabs, heavy extensions, or resource constraints:

Use Chrome's Task Manager

  1. Press Shift + Esc to open Chrome's built-in Task Manager
  2. Look at the Memory and CPU columns
  3. Identify tabs or extensions using excessive resources
  4. Select them and click End process

Disable Hardware Acceleration

If Chrome displays graphics glitches

  1. Go to Settings → Advanced → System
  2. Toggle off Use hardware acceleration when available
  3. Relaunch Chrome for changes to take effect

Manage Tabs Better

  • Install the Tab Groups extension to organize tabs
  • Use OneTab extension to suspend inactive tabs
  • Avoid having more than 10-15 tabs open simultaneously
  • Pin tabs you use constantly to save memory

5. Fix "Aw, Snap" Errors

The "Aw, Snap" error indicates that a web page has crashed. This is different from Chrome itself crashing.

Error TypeCauseFix
Aw, Snap on all pagesChrome profile corruptedCreate new profile (see Section 3)
Aw, Snap on specific siteSite compatibility issueClear site cookies and cache
Aw, Snap with extensionsExtension conflictDisable all extensions
Aw, Snap after updateSoftware conflictReset Chrome settings

Additional fixes for "Aw, Snap"

  1. Clear the specific site's data: Settings → Privacy → Site settings → Cookies → See all cookies → Find the site → Delete
  2. Try the site in incognito mode — if it works, the issue is with cookies or extensions
  3. Update your graphics drivers (especially on Windows)
  4. Run Chrome with the --disable-gpu-driver-bug-workarounds flag

6. Pages Won't Load

Troubleshoot loading issues

  1. Check your internet — try loading websites in other browsers
  2. Flush DNS cache — open Command Prompt and type: ipconfig /flushdns
  3. Change DNS servers — go to Network Settings → DNS → enter 8.8.8.8 and 8.8.4.4
  4. Disable proxy — Settings → System → Open proxy settings → ensure no proxy is configured
  5. Clear socket pools — type chrome://net-internals/#sockets → click "Flush socket pools"

Specific site won't load

  • Clear that site's cookies: Settings → Privacy → Site settings → Cookies → See all cookies
  • Check if the site is blocked by an extension (try incognito mode)
  • Check your hosts file for any custom DNS entries
  • Try using a different DNS provider (Cloudflare 1.1.1.1, Google 8.8.8.8)

7. Extension-Related Issues

Extensions are a common source of Chrome problems. Here's how to manage them:

How to safely disable extensions

  1. Type chrome://extensions in the address bar
  2. Toggle off Developer mode (top right)
  3. Turn off all extensions by toggling each one off
  4. Enable them one by one to identify the problematic one

Common problematic extension types

  • Ad blockers — can break certain website functionality
  • VPN/Proxy extensions — can cause connection issues
  • Shopping/comparison extensions — often bloated and slow
  • Toolbar utilities — frequently cause crashes
  • Outdated extensions — may not be compatible with newer Chrome versions
Tip: Review your extensions quarterly. If you haven't used an extension in 30 days, remove it.

8. Chrome on Mobile (Android & iOS)

Android

Fix Chrome on Android

  1. Update Chrome — Play Store → Chrome → Update
  2. Clear cache — Settings → Apps → Chrome → Storage → Clear Cache
  3. Clear data — Settings → Apps → Chrome → Storage → Clear Data (will sign you out)
  4. Restart your phone — hold power button → Restart
  5. Reinstall — long-press Chrome → Uninstall → reinstall from Play Store

iPhone / iPad

  1. Update Chrome — App Store → Chrome → Update
  2. Force close — swipe up from bottom → swipe away Chrome card
  3. Clear history — Chrome → three dots → Settings → Privacy → Clear Browsing Data
  4. Reinstall — long-press app → Remove App → reinstall from App Store

Common mobile issues and fixes

IssueFix
Chrome draining batteryClose background tabs, disable push notifications
Chrome won't load pagesCheck Wi-Fi, clear cache, restart device
Chrome keeps closingUpdate app, free up storage space
Can't download filesCheck storage, allow download permissions
