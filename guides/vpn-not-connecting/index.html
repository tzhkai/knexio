1. Quick First Checks

Start here before anything else

  1. Check your regular internet connection first — visit a website without VPN active.
  2. Restart the VPN app completely (quit and reopen, not just minimize).
  3. Try a different VPN server location — the server you're using may be overloaded or down.
  4. Restart your router and modem (unplug for 30 seconds).
  5. Check your VPN provider's status page or Twitter/X for outage announcements.
  6. Verify your VPN subscription is active and not expired.
  7. Try connecting on a different network (mobile hotspot) to isolate the issue.
Tip: Many VPN providers maintain status pages showing server health. Check your provider's website for real-time server status before troubleshooting further.

2. Change Server or Protocol

Switching protocol is often the fastest fix for a stuck VPN connection.

Tip: Most modern VPN apps (NordVPN, ExpressVPN, Mullvad, ProtonVPN) let you change protocol in Settings. Switch from your current protocol to WireGuard or OpenVPN UDP.

How to change protocol by app

  1. NordVPN: Settings → Connection → VPN Protocol → Select protocol
  2. ExpressVPN: Settings → Protocol → Select protocol
  3. Surfshark: Settings → Advanced → Protocol → Select protocol
  4. ProtonVPN: Settings → Connection → Protocol → Select protocol
  5. Mullvad: Settings → Preferences → Bridge mode/Transport mode

3. Fix VPN on Windows 10/11

Windows Users: Complete PC VPN troubleshooting.

Update VPN drivers

Reinstall TAP/TUN adapter (OpenVPN)

  1. Open Device Manager (Win+X → Device Manager).
  2. Expand Network adapters. Look for "TAP-Windows Adapter" or "WireGuard Tunnel".
  3. Right-click → Uninstall device.
  4. Uninstall and reinstall your VPN app — it will reinstall the driver automatically.

Reset network stack

Network reset commands

  1. Open Command Prompt as Administrator (Win+S → type "cmd" → right-click → Run as administrator).
  2. Run: netsh winsock reset — press Enter.
  3. Run: netsh int ip reset — press Enter.
  4. Run: ipconfig /flushdns — press Enter.
  5. Restart your PC.

DNS leak / stuck DNS

Fix DNS issues

  1. Win+R → type ncpa.cpl → press Enter to open Network Connections.
  2. Right-click your active adapter → Properties → Internet Protocol Version 4 (TCP/IPv4) → Properties.
  3. Set DNS to Obtain DNS server address automatically, or use 1.1.1.1 / 8.8.8.8.
  4. Ensure "Use default gateway on remote network" is checked in VPN adapter properties.

Windows-specific VPN issues

  1. VPN blocks internet: Check "Split tunneling" settings in your VPN app.
  2. Error 809: Enable IPsec services: services.msc → IPsec Policy Agent → Start.
  3. Error 691: Check username/password; re-enter credentials.
  4. Error 800: VPN server unreachable; try different server.
  5. Always On VPN issues: Check group policy settings if on a work PC.

4. Fix VPN on Mac

Mac Users: Complete macOS VPN troubleshooting.

macOS VPN fixes

  1. Quit the VPN app fully: right-click dock icon → Quit.
  2. Open System Settings → Network — if you see a leftover VPN entry with a warning, click it and delete it, then reconnect via your VPN app.
  3. Reset network settings: open Terminal and run sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder.
  4. Check macOS firewall: System Settings → Network → Firewall — if on, ensure your VPN app is in the allowed list.
  5. Reinstall the VPN app by dragging it to the Trash, then downloading fresh from the provider's website.
  6. Check for Little Snitch or other network filters that might block VPN connections.
  7. Try using the VPN's native app rather than manual L2TP/IKEv2 configuration.

5. Fix VPN on iPhone & Android

Mobile Users: Complete iOS and Android VPN troubleshooting.

iPhone (iOS)

iOS VPN fixes

  1. Settings → General → VPN & Device Management → VPN. Delete any old VPN profiles, then re-add via your VPN app.
  2. Toggle Airplane Mode on for 10 seconds, then off.
  3. Settings → General → Transfer or Reset iPhone → Reset → Reset Network Settings (loses Wi-Fi passwords).
  4. Update the VPN app from the App Store.
  5. Check for iOS updates: Settings → General → Software Update.
  6. Try using IKEv2 protocol specifically — it works well with iOS network transitions.
  7. Disable "Limit IP Address Tracking" if using iCloud Private Relay.

Android

Android VPN fixes

  1. Settings → Apps → [Your VPN app] → Storage → Clear Cache.
  2. Settings → Network & Internet → VPN — remove any old manual VPN configurations.
  3. Disable Battery Optimization for your VPN app: Settings → Battery → Battery Optimization → [VPN app] → Don't Optimize.
  4. Enable "Always-on VPN" if you keep getting disconnected: Settings → Network → VPN → your VPN → gear icon → Always-on VPN.
  5. Check for "Data Saver" or "Battery Saver" modes that might restrict VPN.
  6. Try WireGuard protocol — it's lightweight and works well on mobile.
  7. Some manufacturers (Xiaomi, Huawei) have aggressive battery management — add VPN to protected apps.

6. Firewall & Antivirus Conflicts

Security software is one of the most common causes of VPN failures.

Fix firewall conflicts

  1. Windows Defender Firewall: Control Panel → Windows Defender Firewall → Allow an app → Add your VPN app to the allowed list for both Private and Public networks.
  2. Third-party antivirus (Bitdefender, McAfee, Norton, Kaspersky): temporarily disable the firewall module and test the VPN. If it connects, add the VPN as an exception in your antivirus settings.
  3. Corporate/school network: Many enterprise networks block VPN ports. Try using OpenVPN TCP on port 443 — this tunnels VPN traffic over HTTPS, which is rarely blocked.
  4. Router firewall: Log into your router and ensure VPN passthrough is enabled for PPTP, L2TP, and IPSec.
Security Note: Only disable antivirus/firewall temporarily for testing. Always re-enable protection after diagnosing the issue.

7. VPN Protocol: Which to Choose

If you're stuck on a specific protocol, switching is almost always worth trying first:

Protocol selection guide

  1. Try WireGuard — fastest, simplest, works in most environments. Best for streaming and general use.
  2. OpenVPN UDP — reliable fallback. Port 1194. Good balance of speed and security.
  3. OpenVPN TCP port 443 — mimics HTTPS traffic, bypasses most network restrictions. Slower but most reliable.
  4. IKEv2 — fast reconnection when switching networks (Wi-Fi to mobile). Great for mobile devices.
  5. SSTP (Windows only) — uses HTTPS (port 443), hard to block. Good for Windows users facing blocks.
  6. Avoid PPTP — outdated and insecure, easily blocked and broken.

8. ISP Blocking VPN

Some internet service providers — especially in certain countries — actively block VPN traffic using Deep Packet Inspection (DPI).

Bypass ISP VPN blocking

  1. Enable your VPN's obfuscation/stealth mode (available in NordVPN, ExpressVPN, Mullvad, Astrill). This disguises VPN traffic as normal HTTPS traffic.
  2. Use OpenVPN TCP on port 443 — the most universally unblocked option.
  3. Try Shadowsocks or V2Ray plugins if your VPN supports them (more advanced).
  4. Switch from your home network to a mobile hotspot to verify whether it's the ISP or your router causing the block.
  5. Use Double VPN or Multi-hop features to hide VPN traffic patterns.
  6. Try connecting to specialty servers like "Obfuscated" or "Stealth" if your provider offers them.
Note: VPN legality varies by country. Ensure VPN use complies with local laws in your region.

9. Slow VPN Speeds

Speed up your VPN

  1. Connect to a closer server: Distance significantly affects latency and speed.
  2. Switch to WireGuard: It's faster than OpenVPN on most connections.
  3. Try different servers: Some servers may be overloaded. Try multiple in the same region.
  4. Change protocol: UDP is faster than TCP. WireGuard is faster than both.
  5. Check your base speed: Run a speed test without VPN to know your maximum.
  6. Disable unnecessary features: Turn off Double VPN, Onion over VPN, or other advanced features if not needed.
  7. Use split tunneling: Route only necessary traffic through VPN.
  8. Try different ports: Some ports may be throttled by your ISP.

10. VPN Keeps Disconnecting

Fix frequent disconnections

  1. Enable kill switch: Most VPN apps have a kill switch that blocks internet if VPN disconnects. Enable it to prevent data leaks.
  2. Disable battery optimization: On mobile, battery saving features often kill VPN connections.
  3. Use IKEv2 protocol: It handles network changes (Wi-Fi to mobile) better than OpenVPN.
  4. Check sleep settings: Disable sleep/hibernate while VPN is active on PCs.
  5. Enable auto-connect: Most VPN apps can auto-reconnect when disconnected.
  6. Check router settings: Some routers have aggressive connection timeouts.
  7. Try different server: The server you're using may be unstable.

11. Specific VPN App Fixes

NordVPN

  1. Try different specialty servers (P2P, Double VPN, Onion over VPN).
  2. Enable "Obfuscated servers" if regular servers don't connect.
  3. Use "Threat Protection" settings to ensure it's not blocking connections.
  4. Check if "Kill Switch" is blocking internet when disconnected.

ExpressVPN

  1. Use the "Lightway" protocol for best performance.
  2. Try "Smart Location" to find the best server automatically.
  3. Check "Network Lock" (kill switch) settings.
  4. Use the built-in speed test to find fastest servers.

Surfshark

  1. Enable "NoBorders" mode for restrictive networks.
  2. Try "Camouflage Mode" to hide VPN usage.
  3. Use "Rotating IP" feature for better connectivity.
  4. Check "CleanWeb" isn't blocking necessary connections.

ProtonVPN

  1. Try "Stealth" protocol for bypassing blocks.
  2. Enable "Alternative Routing" if connections fail.
  3. Check "NetShield" settings aren't too restrictive.
  4. Use "VPN Accelerator" for better speeds.

12. Frequently Asked Questions

Common VPN questions answered

Why is my VPN stuck on 'Connecting'?

A VPN stuck on Connecting usually means the VPN server is unreachable, your firewall is blocking the connection, or the VPN protocol is being throttled by your network. Try switching to a different VPN server, changing the VPN protocol (e.g., from OpenVPN to WireGuard), or disabling your firewall temporarily to test.

Why does my VPN keep disconnecting?

Frequent VPN disconnections are caused by an unstable internet connection, power-saving settings turning off the network adapter, or the VPN server being overloaded. Ensure your internet is stable, disable PC sleep/hibernate while connected, and try connecting to a less-loaded server.

Why can't I connect to VPN on Windows?

On Windows, VPN failures are often caused by outdated TAP/TUN drivers, conflicting third-party firewall software, or Windows Firewall blocking VPN ports. Update the VPN app and its drivers, temporarily disable third-party antivirus/firewall to test, and ensure that ports 1194 (OpenVPN), 1723 (PPTP), or 500/4500 (IKEv2) are not blocked by your router.

Why is VPN not working on mobile data?

Some mobile carriers block VPN protocols, especially PPTP and IKEv2 on certain networks. Try switching to WireGuard or OpenVPN UDP. Also check that your carrier's data plan doesn't restrict VPN usage (some prepaid plans do).

How do I fix VPN on iPhone?

On iPhone: go to Settings > General > VPN & Device Management > VPN. Delete any old VPN profiles, then re-add via your VPN app. Toggle Airplane Mode on for 10 seconds, then off. If issues persist, go to Settings > General > Transfer or Reset iPhone > Reset > Reset Network Settings.

How do I fix VPN on Android?

On Android: go to Settings > Apps > [Your VPN app] > Storage > Clear Cache. Then go to Settings > Network & Internet > VPN and remove any old manual VPN configurations. Disable Battery Optimization for your VPN app and enable 'Always-on VPN' if needed.

Why is my VPN so slow?

Slow VPN speeds are usually caused by connecting to a distant server, server overload, using a slow protocol (like OpenVPN TCP), or your ISP throttling VPN traffic. Try connecting to a closer server, switching to WireGuard protocol, or using obfuscation features.

Can my ISP block VPN?

Yes, ISPs can block VPNs by detecting and blocking VPN protocol ports or using Deep Packet Inspection (DPI) to identify VPN traffic. To bypass this, use obfuscated servers, switch to TCP port 443 (mimics HTTPS), or use stealth protocols like Shadowsocks.

Which VPN protocol should I use?

WireGuard is the fastest and most modern protocol. OpenVPN UDP is reliable for most situations. OpenVPN TCP on port 443 is best for bypassing blocks. IKEv2 is good for mobile devices as it handles network switches well. Avoid PPTP as it's insecure.

Why does VPN block my internet?

If VPN connects but you lose all internet access, it's usually a DNS leak protection issue, kill switch blocking traffic, or split tunneling misconfiguration. Try changing DNS servers in the VPN app, disabling the kill switch temporarily, or checking split tunneling settings.
