Google Maps Not Working? Here's How to Fix It

Google Maps problems — blank maps, location not found, directions not loading — usually come down to internet connectivity, GPS permissions, or a cache issue. Here are the fixes for Android, iPhone, and browser.
Check Google Maps status: Visit maps.google.com on a different device or browser to confirm if the issue is with Google's service or your device specifically.

Fixes for Android

Step 1 — Check Internet Connection

Google Maps requires internet for live maps and directions. Open a browser and load any website. If internet is broken, fix connectivity first.

Step 2 — Enable Location / GPS

Settings → Location → Turn on location. Also check: Settings → Location → App permissions → Maps → Set to "While using the app" or "All the time" for navigation.

Step 3 — Clear Cache and Data

Settings → Apps → Google Maps → Storage → Clear Cache. If the problem persists, tap Clear Data (this resets offline maps and preferences). Relaunch Maps.

Step 4 — Update Google Maps

Open Play Store → search Google Maps → Update if available. Outdated versions can break against newer API changes.

Step 5 — Calibrate Compass

If your location is wrong on the map, open Maps → blue dot → Calibrate compass → Move phone in figure-8 pattern until calibration completes.

Fixes for iPhone

Step 1 — Grant Location Permission

Settings → Privacy & Security → Location Services → Google Maps → Select While Using the App or Always. Ensure Location Services is on at the top of this screen.

Step 2 — Force Quit and Reopen

Swipe up from the bottom (or double-click Home button) → swipe Google Maps up to close it → Reopen Maps.

Step 3 — Update the App

App Store → profile icon → Check for Google Maps updates and install.

Step 4 — Reinstall Google Maps

Delete Maps and reinstall from the App Store. This resolves corrupted data that clearing cache can't fix on iOS.

Fixes for Browser (maps.google.com)

Step 1 — Clear Browser Cache

Chrome: Ctrl+Shift+Delete → Select "Cached images and files" → Clear data. Reload maps.google.com.

Step 2 — Disable Browser Extensions

Ad blockers and privacy extensions can block Google Maps scripts. Try opening Maps in an Incognito/Private window to bypass extensions.

Step 3 — Enable JavaScript

Chrome: Settings → Privacy and Security → Site Settings → JavaScript → Ensure it's allowed. Google Maps is JavaScript-heavy and won't work without it.

Step 4 — Update Your Browser

Chrome: Menu → Help → About Google Chrome → Update if available. Firefox: Menu → Help → About Firefox → Update.

Frequently Asked Questions

Why does Google Maps keep crashing?

Frequent crashes usually indicate a corrupted app installation or the app is outdated. Clear cache, update the app, and if crashes continue, reinstall Google Maps.
