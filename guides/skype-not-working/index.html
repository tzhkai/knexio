Skype Not Working? How to Fix Common Skype Problems

Skype remains a popular communication tool for video calls, voice calls, and instant messaging. When it stops working, these fixes will help you get back to connecting with friends, family, and colleagues.

Common Causes of Skype Problems

  • Network connectivity issues: Unstable internet or firewall blocking Skype ports
  • Outdated Skype application: Older versions may have compatibility issues
  • Camera or microphone in use: Other apps may be using your devices
  • Incorrect device settings: Wrong speakers or microphone selected
  • Account or authentication problems: Microsoft account issues
  • Server outages: Check status.skype.com for known issues

Fix 1: Skype Not Connecting

If Skype won't sign in or shows connection errors:

  1. Check if Skype servers are down at status.skype.com
  2. Restart Skype completely (right-click in taskbar → Quit) and reopen
  3. Check your internet connection by opening other websites or apps
  4. Switch from Wi-Fi to mobile data or vice versa to test different network
  5. Clear Skype cache (see cache section below)
  6. Reinstall Skype if issues persist

Fix 2: Check for Updates

Outdated Skype versions often cause connection and performance issues:

  1. Open Skype and click your profile picture
  2. Select "Check for Skype updates"
  3. If an update is available, it will download automatically
  4. Restart Skype to apply updates
  5. Alternatively, download the latest version from skype.com/download

Fix 3: Audio/Video Troubleshooting

If you can connect but can't hear or see others:

No Audio Output

  1. Click the "+" button in a call → Audio settings
  2. Select the correct speaker from the dropdown (check it's not "None")
  3. Check Windows/macOS volume settings (System Preferences → Sound on Mac)
  4. Ensure you're not muted (look for the microphone icon with a line through it)
  5. Test with "Make a test call" in Skype settings → Audio & Video

Microphone Not Working

  1. Click the "+" button → Audio settings
  2. Select your microphone from the dropdown
  3. On Windows: Go to Settings → Privacy & Security → Microphone → Enable "Let apps access your microphone" → Find Skype and enable
  4. On Mac: Go to System Settings → Privacy & Security → Microphone → Enable Skype
  5. Close other apps that might be using the microphone (Zoom, Teams, Discord)
  6. Try a different microphone to test if hardware is working

Camera/Video Not Working

  1. Click the video icon to enable video (it must be turned on manually)
  2. Check camera is selected in call settings (click arrow next to camera icon)
  3. On Windows: Settings → Privacy & Security → Camera → Enable "Let apps access your camera" → Enable Skype
  4. On Mac: System Settings → Privacy & Security → Camera → Enable Skype
  5. Close other apps using the camera (Zoom, Teams, OBS, FaceTime)
  6. Test camera in other apps (e.g., Windows Camera app or Photo Booth on Mac) to confirm it works

Echo and Audio Feedback

  • Use headphones instead of speakers (speakers pick up mic audio and create echo)
  • Lower speaker volume
  • Mute yourself when not speaking
  • Ask others to mute if they're causing echo
  • Move microphone away from speakers
Tip: Use Ctrl+Shift+M to mute/unmute quickly during calls on Windows, Cmd+Shift+M on Mac.

Fix 4: Connection & Firewall Issues

Network problems often cause Skype connection failures:

Required Ports

Skype requires these ports to function properly:

  • TCP 443 — For authentication and signaling
  • UDP 3478, 3479, 3480 — For audio/video connections
  • TCP 80 — Fallback connection

Allow Skype Through Firewall (Windows)

  1. Open Windows Security → Firewall & network protection
  2. Click "Allow an app through firewall"
  3. Click "Change settings" → Find "Skype" in the list
  4. Enable both Private and Public for Skype
  5. If not listed, click "Allow another app" → Browse to where Skype is installed (usually C:\Program Files\Skype\Phone)

Allow Skype Through Firewall (Mac)

  1. Go to System Settings → Network → Firewall
  2. If enabled, click "Firewall Options"
  3. Add "Skype" to the allowed apps list
  4. Or go to System Settings → Privacy & Security → Full Disk Access → Add Skype

VPN and Proxy Issues

  1. Disconnect VPN temporarily to test if it's blocking Skype
  2. Try bypassing proxy in Skype settings → Advanced → Connection
  3. Corporate networks may block Skype — contact your IT department
  4. Try using a different network (mobile hotspot) to isolate the issue

Fix 5: Login Problems

Can't Sign In

  1. Verify your Microsoft account credentials at account.microsoft.com
  2. Use the correct Skype name or email associated with your account
  3. Reset password at account.microsoft.com/password
  4. Try the web version at web.skype.com
  5. Clear browser cookies and try again

Account Locked

If your account is locked for security reasons:

  1. Wait 24 hours and try again
  2. Use the account recovery option at account.microsoft.com
  3. Contact Skype support for account restoration
  4. Check your email for any security alerts from Microsoft

Two-Factor Authentication Issues

  1. If you have 2FA enabled, you'll need your authenticator app code
  2. If you lost access to your 2FA device, use a backup code
  3. Contact Microsoft account support if you have no backup codes

Fix 6: Update Procedures

Check for Updates (Desktop)

  1. Open Skype and click your profile picture
  2. Select "Check for Skype updates"
  3. If an update is available, it will download automatically
  4. Restart Skype to apply updates

Manual Download

Download the latest Skype from skype.com/download for Windows, Mac, Linux, iOS, or Android.

Update on Mobile

  1. iOS: Open App Store → Tap profile → Scroll to Updates → Update Skype
  2. Android: Open Play Store → Tap profile → Manage apps → Updates available → Update Skype

Fix 7: Cache Clearing

Clearing Skype cache resolves many issues including slow performance and connection problems:

Clear Cache on Windows

  1. Close Skype completely (right-click taskbar icon → Quit)
  2. Press Win + R, type %AppData%\Skype, press Enter
  3. Delete the "Cache" folder if it exists
  4. Also check %LocalAppData%\Skype and delete cache folders there
  5. Restart Skype

Clear Cache on Mac

  1. Quit Skype (Cmd + Q)
  2. Open Finder → Go → Go to Folder → type ~/Library/Application Support/Skype
  3. Delete the "Cache" folder
  4. Also clear ~/Library/Caches/com.skype
  5. Restart Skype

Clear Cache on Mobile

  1. iOS: Delete and reinstall the app (iOS doesn't allow individual cache clearing)
  2. Android: Settings → Apps → Skype → Storage → Clear Cache

Frequently Asked Questions

Why does Skype keep disconnecting during calls?

Skype disconnections are usually caused by unstable internet, firewall blocking, or too many applications using bandwidth. Try using a wired Ethernet connection instead of Wi-Fi, close other bandwidth-heavy applications, and ensure your firewall allows Skype.

Why can't I see my contacts on Skype?

If contacts aren't showing, sign out and sign back in. Also check that you're viewing the correct contact list (some accounts have multiple contact lists). If the issue persists, clear cache or reinstall Skype.

How do I fix poor call quality on Skype?

Poor call quality can be improved by: using a wired connection instead of Wi-Fi, closing other applications using internet, moving closer to your router, using headphones to avoid echo, and lowering video quality in call settings.

Can I use Skype without a Microsoft account?

Yes, you can create a Skype-specific account at skype.com. However, linking your Microsoft account provides additional features and makes account recovery easier. Some features require a Microsoft account.

Why does Skype say "Searching" and not connect?

This usually indicates a network issue. Check your internet connection, try clearing your cache, restart Skype, or try a different network. If using a corporate VPN, contact your IT department.
