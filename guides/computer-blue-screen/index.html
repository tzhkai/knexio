What is the Blue Screen of Death?

The Blue Screen of Death (BSOD), officially called a Stop Error, occurs when Windows encounters a critical system error it cannot recover from. The system stops to prevent damage and displays a blue screen with error information.

Common Causes of BSOD:

  • Driver issues: Outdated, corrupted, or incompatible drivers
  • Hardware failures: Failing RAM, hard drive, or other components
  • Overheating: CPU or GPU running too hot
  • Software conflicts: Incompatible programs or malware
  • Windows updates: Corrupted or failed system updates
  • Overclocking: Unstable CPU/GPU overclock settings

Common BSOD Error Codes

Understanding your error code helps identify the root cause:

Error Code Meaning Likely Cause
CRITICAL_PROCESS_DIED Critical system process stopped Corrupted system files, driver issues
IRQL_NOT_LESS_OR_EQUAL Memory access violation Faulty RAM, bad drivers
PAGE_FAULT_IN_NONPAGED_AREA Memory page fault RAM issues, corrupted pagefile
SYSTEM_THREAD_EXCEPTION System thread error Graphics driver, incompatible software
KMODE_EXCEPTION Kernel mode exception Driver conflict, hardware failure
NTFS_FILE_SYSTEM File system error Hard drive corruption, bad sectors
UNMOUNTABLE_BOOT_VOLUME Cannot access boot drive Hard drive failure, corrupted boot

First Step: Boot into Safe Mode

Safe Mode loads Windows with minimal drivers and services, making it easier to troubleshoot.

Enter Safe Mode (Windows 10/11):

  1. Hold Shift and click Restart from the login screen
  2. Or: Force shutdown 3 times during boot to enter Recovery
  3. Select Troubleshoot → Advanced options → Startup Settings
  4. Click Restart, then press 4 or F4 for Safe Mode
  5. Press 5 or F5 for Safe Mode with Networking

Command Line Methods (if system boots):

# Enable Safe Boot (requires restart)
bcdedit /set {default} safeboot minimal

# Enable Safe Boot with Networking
bcdedit /set {default} safeboot network

# Disable Safe Boot after fixing
bcdedit /deletevalue {default} safeboot

# One-time Safe Mode boot
bcdedit /set {current} safeboot minimal
shutdown /r /t 0

Windows Recovery Environment (WinRE) Commands:

# Access WinRE from command line
reagentc /boottore

# List WinRE status
reagentc /info

# Enable/disable WinRE
reagentc /enable
reagentc /disable
✅ If Windows works in Safe Mode: The problem is likely a driver or startup program. Use the fixes below to identify and resolve the issue.

Fix 1: Update or Rollback Drivers

Faulty drivers are the most common cause of BSOD.

Update Drivers:

  1. Boot into Safe Mode
  2. Press Windows + X, select Device Manager
  3. Expand categories and look for yellow warning icons
  4. Right-click problematic device → Update driver
  5. Select "Search automatically for drivers"

Command Line Driver Management:

# List all drivers with details
driverquery /v /fo csv > drivers.csv

# Export driver list to file
driverquery /si > drivers.txt

# Check for problematic drivers
pnputil /enum-drivers

# Update specific driver
pnputil /add-driver "driver.inf" /install

# Rollback driver
pnputil /rollback-driver "DeviceID"

# Force Windows Update to check for driver updates
usoclient StartScan

Rollback Recent Driver Updates:

If BSOD started after a driver update:

  1. Device Manager → Right-click device → Properties
  2. Driver tab → Roll Back Driver
  3. Follow prompts and restart

Command Line Rollback:

# Find device instance ID
wmic path win32_pnpentity get caption,deviceid

# Rollback specific driver
devcon rollback "PCI\VEN_10DE&DEV_1C03&SUBSYS_..."

# Disable problematic driver
devcon disable "PCI\VEN_10DE&DEV_1C03&SUBSYS_..."

# Enable driver
devcon enable "PCI\VEN_10DE&DEV_1C03&SUBSYS_..."
💡 Priority Drivers to Check: Graphics card (NVIDIA/AMD/Intel), network adapters, storage controllers, and USB controllers.

Driver-Specific Commands:

  • NVIDIA: Download DDU (Display Driver Uninstaller) for clean removal
  • AMD: Use AMD Cleanup Utility before installing new drivers
  • Intel: Run Intel Driver & Support Assistant for updates

Fix 2: Install Windows Updates

Microsoft regularly releases patches that fix BSOD-causing bugs.

Check for Updates:

  1. Settings → Windows Update (Windows 11) or Update & Security (Windows 10)
  2. Click "Check for updates"
  3. Install all available updates
  4. Restart when prompted

Command Line Update Management:

# Check for updates
usoclient StartScan

# Check update history
wmic qfe list brief /format:table

# Uninstall specific update
wusa /uninstall /kb:5005565 /quiet /norestart

# Force Windows Update service reset
net stop wuauserv
net stop bits
del /q /s C:\Windows\SoftwareDistribution\Download\*
net start wuauserv
net start bits
⚠️ If BSOD started after an update: Go to Settings → Windows Update → Update history → Uninstall updates. Remove the most recent quality or feature update.

Fix 3: Registry Fixes for BSOD Issues

Critical Registry Tweaks for Stability

Warning: Always backup registry first: reg export HKLM\SYSTEM\CurrentControlSet\Services C:\regbackup.reg

# Increase crash dump settings
reg add "HKLM\SYSTEM\CurrentControlSet\Control\CrashControl" /v CrashDumpEnabled /t REG_DWORD /d 1 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Control\CrashControl" /v Overwrite /t REG_DWORD /d 1 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Control\CrashControl" /v DumpFile /t REG_EXPAND_SZ /d "%SystemRoot%\MEMORY.DMP" /f

# Disable driver signature enforcement (temporary troubleshooting)
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Configuration Manager" /v EnableSafeMode /t REG_DWORD /d 1 /f

# Increase timeout for hung services
reg add "HKLM\SYSTEM\CurrentControlSet\Control" /v ServicesPipeTimeout /t REG_DWORD /d 60000 /f

# Disable Windows Error Reporting if causing issues
reg add "HKLM\SOFTWARE\Microsoft\Windows\Windows Error Reporting" /v Disabled /t REG_DWORD /d 1 /f

Windows 10/11 Specific Registry Fixes:

# Windows 10 - Disable Fast Startup (can cause driver issues)
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Power" /v HiberbootEnabled /t REG_DWORD /d 0 /f

# Windows 11 - Disable virtualization-based security if causing conflicts
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 0 /f

# Both - Increase paging file size for memory-related BSOD
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v PagingFiles /t REG_MULTI_SZ /d "C:\pagefile.sys 4000 8000" /f

Fix 4: Check Your RAM

Faulty RAM is a common BSOD culprit. Windows has a built-in memory diagnostic tool.

Run Windows Memory Diagnostic:

  1. Press Windows + R, type mdsched.exe and press Enter
  2. Choose "Restart now and check for problems"
  3. Your PC will restart and run the memory test
  4. Wait for completion (15-30 minutes)
  5. Check results in Event Viewer after boot

Advanced Memory Testing Commands:

# Schedule memory test (next reboot)
mdsched.exe /schedule

# Check memory test results
wevtutil qe System /q:"*[System[Provider[@Name='Microsoft-Windows-MemoryDiagnostics-Results']]]" /c:5 /rd:true /f:text

# Check Windows reliability history for memory errors
Get-WinEvent -FilterHashtable @{LogName='System'; ID='2001'} | Select-Object -First 10

# Use Windows Performance Recorder for memory analysis
wpr -start GeneralProfile -filemode

Third-Party RAM Testing Tools (bootable):

  • MemTest86: Free, boots from USB, tests RAM thoroughly
  • HCI MemTest: Tests RAM while Windows is running
  • Prime95: Stress test that reveals memory instability
🚨 If errors are found: Your RAM may be faulty. Try reseating RAM sticks, testing one stick at a time, or replacing defective modules.

Command Line Memory Info:

# Get detailed RAM information
wmic memorychip get BankLabel, Capacity, Speed, MemoryType

# Check current memory usage
wmic OS get FreePhysicalMemory,TotalVisibleMemorySize /Value

# Check pagefile usage
wmic pagefile get Name, CurrentUsage, PeakUsage, AllocatedBaseSize

Fix 5: Check Disk for Errors

File system corruption can cause BSOD. Use CHKDSK to scan and repair.

Run CHKDSK:

  1. Press Windows + X, select Terminal (Admin) or Command Prompt (Admin)
  2. Type:
    chkdsk C: /f /r
  3. Press Enter and type Y when prompted
  4. Restart your computer
  5. The scan will run before Windows loads

Fix 6: System Restore

If BSOD started recently, restore Windows to a working state.

Perform System Restore:

  1. Search for "Create a restore point" and open it
  2. Click "System Restore"
  3. Choose "Recommended restore" or select a different point
  4. Pick a date before the BSOD started
  5. Follow prompts and restart
⚠️ Note: System Restore won't affect personal files but may remove recently installed programs and drivers.

Hardware Issues

If software fixes don't resolve BSOD, check your hardware:

Common Hardware Culprits:

  • Overheating: Clean dust from fans, replace thermal paste
  • Failing hard drive: Listen for clicking sounds, check SMART status
  • Loose connections: Reseat RAM, graphics card, and cables
  • Power supply: Insufficient or failing PSU can cause crashes
  • Overclocking: Reset BIOS to default if you've overclocked

Check System Temperature:

Download HWMonitor or Core Temp. If CPU exceeds 85°C or GPU exceeds 90°C under load, overheating may be the cause.

Fix 7: When to Reset or Reinstall Windows

Consider Windows Reset/Reinstall When:

  • BSOD occurs randomly with different error codes
  • System files are corrupted beyond SFC/DISM repair
  • Malware infection suspected as root cause
  • Hardware tests pass but BSOD persists
  • Multiple drivers fail consistently
  • Windows becomes unstable after major update

Reset Options (Windows 10/11):

  1. Keep my files: Settings → System → Recovery → Reset this PC
  2. Remove everything: Clean install, backup data first
  3. Cloud reinstall: Downloads fresh Windows from Microsoft servers
  4. Local reinstall: Uses existing Windows installation files

Command Line Reset Methods:

# Windows 10/11 Reset command
systemreset --factoryreset

# Access Windows Recovery Environment
reagentc /boottore

# Create recovery drive
reagentc /setreimage /path "D:\Recovery\WindowsRE"

# Check if system can be reset
systemreset --? | findstr "factoryreset"

Complete Clean Install (Advanced):

  • Create Windows installation media (USB/DVD)
  • Backup personal files, drivers, activation key
  • Boot from installation media
  • Custom install → Format system drive
  • Install fresh Windows and drivers

Prevention Tips

  • Keep Windows updated: Install security and driver updates promptly
  • Use reliable antivirus: Malware can corrupt system files
  • Monitor temperatures: Keep your PC cool and clean
  • Avoid sketchy software: Only download from trusted sources
  • Don't ignore warnings: Address system errors before they escalate
  • Regular backups: Use File History or third-party backup software
  • Test hardware periodically: Run memory and disk checks monthly
  • Create system restore points: Before major changes or updates
  • Monitor system logs: Check Event Viewer for warnings/errors
  • Use driver verification: verifier.exe to check for problematic drivers
💡 Proactive BSOD Prevention Commands: 
# Schedule weekly system file check
schtasks /create /tn "WeeklySFC" /tr "sfc /scannow" /sc weekly /d SUN /st 02:00

# Schedule monthly disk check
schtasks /create /tn "MonthlyCHKDSK" /tr "chkdsk C: /f" /sc monthly /d 1 /st 03:00

# Export BSOD minidumps automatically
reg add "HKLM\SYSTEM\CurrentControlSet\Control\CrashControl" /v MinidumpDir /t REG_EXPAND_SZ /d "C:\BSOD_Dumps" /f
