Excel Not Opening? 15 Ways to Fix Excel Problems

Updated March 2026 · 8 min read

Quick Fixes

  • Force quit Excel and restart
  • Check for Excel updates
  • Disable add-ins
  • Repair Office installation
  • Open Excel in Safe Mode

Microsoft Excel is essential for work, finance, and data analysis. When Excel won't open, crashes on startup, or freezes unexpectedly, it can halt your productivity. This guide covers 15 comprehensive solutions to fix Excel issues on both Windows and Mac.

Common Excel Problems

  • Excel won't open or clicking does nothing
  • Excel crashes immediately after opening
  • Excel freezes and becomes unresponsive
  • "Excel is not responding" error
  • Excel files won't open or show blank screen
  • Excel takes forever to load
  • "The application was unable to start correctly" error

1. Restart Excel and Your Computer

The simplest fix often works:

  1. Force quit Excel:
    • Windows Press Ctrl + Shift + Esc, find Excel, right-click → End Task
    • Mac Press Cmd + Option + Esc, select Excel → Force Quit
  2. Wait 10 seconds, then reopen Excel
  3. If that fails, restart your computer completely

2. Open Excel in Safe Mode

Safe Mode disables add-ins and customizations that might be causing issues:

Windows

  1. Press Win + R to open Run dialog
  2. Type excel /safe and press Enter
  3. If Excel opens successfully, the issue is likely caused by an add-in

Mac

  1. Press and hold Ctrl while clicking the Excel icon
  2. Select "New" from the context menu
  3. This launches Excel with add-ins disabled

3. Disable Excel Add-Ins

Add-ins can cause Excel to crash on startup:

Windows

  1. Open Excel in Safe Mode (see Solution 2)
  2. Go to File → Options → Add-Ins
  3. At the bottom, select "COM Add-ins" from the dropdown
  4. Click "Go"
  5. Uncheck all add-ins and click OK
  6. Restart Excel normally
  7. If Excel works, re-enable add-ins one by one to identify the culprit

Mac

  1. Go to Tools → Excel Add-ins
  2. Uncheck all add-ins
  3. Restart Excel
  4. Re-enable add-ins one at a time to find the problem

4. Check for Excel Updates

Windows

  1. Open Excel (if possible) or any Office app
  2. Go to File → Account
  3. Click "Update Options" → "Update Now"
  4. Wait for updates to install

Mac

  1. Open Excel → Help → Check for Updates
  2. Follow the Microsoft AutoUpdate prompts
  3. Or update via App Store → Updates

5. Repair Office Installation

Windows

  1. Open Control Panel → Programs → Programs and Features
  2. Find "Microsoft 365" or "Microsoft Office"
  3. Right-click → Change
  4. Select "Quick Repair" (recommended first) or "Online Repair"
  5. Wait for the repair to complete
  6. Restart your computer

Mac

  1. Close all Office apps
  2. Open Finder → Applications
  3. Find "Microsoft Office" folder
  4. Right-click "Microsoft Word" → Show Package Contents
  5. Navigate to Contents → SharedSupport
  6. Double-click "Microsoft Support and Recovery Assistant"
  7. Follow the repair wizard

6. Clear Excel Registry Keys (Windows Only)

⚠️ Warning: Editing the registry can cause system issues if done incorrectly. Back up your registry first.
  1. Press Win + R, type regedit, press Enter
  2. Navigate to: HKEY_CURRENT_USER\Software\Microsoft\Office\16.0\Excel\Data
  3. Right-click the "Data" folder → Delete
  4. Close Registry Editor and restart Excel
  5. Excel will recreate these keys automatically
Tip: The "16.0" may vary based on your Office version (16.0 = Office 2016/2019/365)

7. Delete Excel Preferences (Mac Only)

  1. Quit all Office applications
  2. Open Finder
  3. Press Cmd + Shift + G to open Go to Folder
  4. Type: ~/Library/Preferences
  5. Find and delete these files:
    • com.microsoft.Excel.plist
    • com.microsoft.office.plist
  6. Restart Excel

8. Check for Corrupted Excel Files

If Excel opens but crashes when opening specific files:

  1. Open Excel in Safe Mode
  2. File → Open → select the problematic file
  3. Click the arrow next to Open → "Open and Repair"
  4. If that fails, try "Recover Text from Any File"

Alternative method:

  • Copy the file to a different location
  • Try opening it on another computer
  • If it works elsewhere, the issue is with your Excel installation

9. Check Available Disk Space

Excel needs sufficient free space to function:

  • Windows: Ensure at least 10GB free space
  • Mac: Ensure at least 15GB free space

Windows

  1. Open File Explorer → This PC
  2. Check drive space
  3. Run Disk Cleanup if needed

Mac

  1. Apple menu → About This Mac → Storage
  2. Click "Manage" to free up space

10. Disable Hardware Graphics Acceleration

  1. Open Excel in Safe Mode
  2. File → Options → Advanced
  3. Scroll down to Display section
  4. Check "Disable hardware graphics acceleration"
  5. Click OK
  6. Restart Excel
Tip: This reduces graphics performance but prevents graphics-related crashes

11. Check for Conflicting Software

Other software can interfere with Excel:

  • Antivirus software - temporarily disable to test
  • Screen recording or overlay software (OBS, NVIDIA GeForce Experience)
  • Cloud sync services (Dropbox, OneDrive) - pause temporarily
  • System optimizers or registry cleaners

12. Update Windows or macOS

Windows

  1. Settings → Windows Update
  2. Check for updates
  3. Install all pending updates
  4. Restart your computer

Mac

  1. Apple menu → System Settings → General → Software Update
  2. Download and install any available updates
  3. Restart your Mac

13. Run Office as Administrator (Windows)

  1. Right-click the Excel icon
  2. Select "Run as administrator"
  3. If prompted by User Account Control, click Yes
Tip: To make this permanent, right-click Excel → Properties → Compatibility → check "Run this program as an administrator"

14. Create a New User Profile

Your user profile may be corrupted:

Windows

  1. Settings → Accounts → Family & other users
  2. Add a new local account
  3. Sign in with the new account
  4. Try opening Excel
  5. If it works, the issue is with your original profile

Mac

  1. System Settings → Users & Groups
  2. Click the lock icon and enter your password
  3. Click the "+" button to create a new user
  4. Log out and log in with the new account
  5. Test Excel

15. Reinstall Microsoft Office

⚠️ Important: Before uninstalling, deactivate your Office license if you have a standalone version. Office 365 users can simply reinstall.

Windows

  1. Open Control Panel → Programs → Programs and Features
  2. Right-click Microsoft Office → Uninstall
  3. Follow the uninstall wizard
  4. Restart your computer
  5. Reinstall Office from office.com
  6. Sign in and activate

Mac

  1. Move Microsoft Office folder from Applications to Trash
  2. Empty Trash
  3. Restart Mac
  4. Download Office from office.com or App Store
  5. Install and sign in

Frequently Asked Questions

Why does Excel keep crashing?

Excel crashes are usually caused by corrupted add-ins, corrupted Excel files, insufficient system resources, or conflicts with other software. Try opening Excel in Safe Mode to identify the issue.

What is Excel Safe Mode and how do I use it?

Safe Mode launches Excel without add-ins, macros, and customizations. On Windows, press Win+R and type excel /safe. On Mac, hold Ctrl while clicking the Excel icon and select "New".

How do I recover an unsaved Excel file?

File → Info → Manage Workbook → Recover Unsaved Workbooks. Or check: C:\Users\[Username]\AppData\Local\Microsoft\Office\UnsavedFiles on Windows.

Will repairing Office delete my files?

No, repairing Office will not delete any of your Excel files. It only repairs the Office application files and registry settings.

Excel opens but shows a blank screen. How to fix?

Try these fixes:

  1. Disable hardware graphics acceleration (Solution 10)
  2. Open Excel → Options → Advanced → Display → Check "Disable Slide Show hardware graphics acceleration"
  3. Delete Excel registry keys (Solution 6)
  4. Repair Office installation (Solution 5)

How much RAM does Excel need?

Excel requires at least 2GB RAM for basic use, 4GB recommended for normal work, and 8GB+ for large workbooks with complex formulas and data analysis.

Can I use Excel Online if the desktop app won't open?

Yes, visit office.com and sign in with your Microsoft account to use Excel Online. This is a good temporary solution while troubleshooting the desktop app.

What if none of these solutions work?

If all solutions fail, contact Microsoft Support directly. You can access help via:

  • File → Help → Contact Support in Excel
  • support.microsoft.com
  • Tweet @MicrosoftHelps
