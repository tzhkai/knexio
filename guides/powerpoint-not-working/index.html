PowerPoint Not Working? 14 Ways to Fix PowerPoint Problems

Updated March 2026 · 7 min read

Quick Fixes

  • Force quit and restart PowerPoint
  • Open in Safe Mode
  • Disable add-ins
  • Repair Office installation
  • Check for updates

PowerPoint is essential for presentations, education, and business communication. When PowerPoint won't open, crashes during editing, or fails to play slides correctly, it can derail your work. This guide provides 14 comprehensive solutions for Windows and Mac users.

Common PowerPoint Problems

  • PowerPoint won't open or clicking does nothing
  • PowerPoint crashes on startup or during use
  • Slides won't play or show black screen
  • "PowerPoint is not responding" error
  • PowerPoint files won't open or are corrupted
  • Audio and video not playing in presentation
  • Animations and transitions not working
  • "Out of memory" errors

1. Restart PowerPoint and Your Computer

Start with the basics:

  1. Force quit PowerPoint:
    • Windows Press Ctrl + Shift + Esc, find PowerPoint, right-click → End Task
    • Mac Press Cmd + Option + Esc, select PowerPoint → Force Quit
  2. Wait 10 seconds, then reopen PowerPoint
  3. If the issue persists, restart your computer completely

2. Open PowerPoint in Safe Mode

Safe Mode disables add-ins and customizations that might be causing crashes:

Windows

  1. Press Win + R to open Run dialog
  2. Type powerpnt /safe and press Enter
  3. If PowerPoint opens successfully, an add-in is likely causing the issue

Mac

  1. Press and hold Ctrl while clicking the PowerPoint icon
  2. Select "New" from the context menu
  3. This launches PowerPoint with add-ins disabled

3. Disable PowerPoint Add-Ins

Add-ins can cause PowerPoint to crash or fail to open:

Windows

  1. Open PowerPoint in Safe Mode
  2. Go to File → Options → Add-Ins
  3. At the bottom, select "COM Add-ins" from the dropdown
  4. Click "Go"
  5. Uncheck all add-ins and click OK
  6. Restart PowerPoint normally
  7. If it works, re-enable add-ins one by one to find the problematic one

Mac

  1. Go to Tools → PowerPoint Add-ins
  2. Uncheck all add-ins
  3. Restart PowerPoint
  4. Re-enable add-ins one at a time to identify the issue

4. Check for PowerPoint Updates

Windows

  1. Open PowerPoint (if possible) or any Office app
  2. Go to File → Account
  3. Click "Update Options" → "Update Now"
  4. Wait for updates to install

Mac

  1. Open PowerPoint → Help → Check for Updates
  2. Follow the Microsoft AutoUpdate prompts
  3. Or update via App Store → Updates

5. Repair Office Installation

Windows

  1. Open Control Panel → Programs → Programs and Features
  2. Find "Microsoft 365" or "Microsoft Office"
  3. Right-click → Change
  4. Select "Quick Repair" (recommended first) or "Online Repair"
  5. Wait for the repair to complete
  6. Restart your computer

Mac

  1. Close all Office apps
  2. Open Finder → Applications
  3. Find "Microsoft Office" folder
  4. Right-click "Microsoft Word" → Show Package Contents
  5. Navigate to Contents → SharedSupport
  6. Double-click "Microsoft Support and Recovery Assistant"
  7. Follow the repair wizard

6. Fix PowerPoint Not Playing Slides

If slides don't play or show black screen:

  1. Start the slide show (F5 or Cmd + Shift + Enter)
  2. If you see a black screen, press any key or click
  3. Check that your presentation is saved as .pptx, not .ppt
  4. Go to Slide Show → Set Up Slide Show
  5. Under "Show type", ensure "Presented by a speaker" is selected
  6. Check "Show slide show on" to ensure correct display is selected
  7. Try changing the resolution: Slide Show → Monitor Resolution

7. Fix Audio and Video Not Playing

  1. Click on the media file (video/audio) on the slide
  2. Go to Playback tab
  3. Check that "Start:" is set to either "In Click Sequence" or "Automatically"
  4. For videos, ensure "Play Full Screen" is checked if desired
  5. Check that volume is not muted in PowerPoint
  6. Test the media file outside PowerPoint to ensure it works
  7. Convert media files to supported formats (MP4 for video, MP3 for audio)
Tip: Always embed media files in the presentation rather than linking them. File → Options → Advanced → Save → Check "Link sounds with file size greater than" and set a high number.

8. Disable Hardware Graphics Acceleration

  1. Open PowerPoint in Safe Mode
  2. File → Options → Advanced
  3. Scroll down to Display section
  4. Check "Disable hardware graphics acceleration"
  5. Click OK
  6. Restart PowerPoint
Tip: This helps if PowerPoint crashes during animations or transitions

9. Check for Corrupted Presentation Files

If PowerPoint opens but crashes on specific files:

  1. Open PowerPoint in Safe Mode
  2. File → Open → select the problematic file
  3. Click the arrow next to Open → "Open and Repair"
  4. If that fails, try inserting slides into a new presentation:
    • Create a new blank presentation
    • Home → New Slide → Reuse Slides
    • Browse to the corrupted file and insert slides

10. Reduce Presentation File Size

Large files can cause PowerPoint to crash or freeze:

  1. File → Info → Compress Media (for videos)
  2. Select "Internet Quality" or "Low Quality"
  3. Compress images: File → Options → Advanced → Image Size and Quality
  4. Check "Discard editing data"
  5. Set default resolution to 150 ppi or lower
  6. Delete unused slides and master slides
  7. Remove embedded fonts if not needed: File → Options → Save

11. Clear PowerPoint Cache (Windows)

  1. Close all Office applications
  2. Press Win + R
  3. Type %appdata%\Microsoft\PowerPoint and press Enter
  4. Delete all files in this folder
  5. Restart PowerPoint

12. Delete PowerPoint Preferences (Mac)

  1. Quit all Office applications
  2. Open Finder
  3. Press Cmd + Shift + G
  4. Type ~/Library/Preferences
  5. Find and delete: com.microsoft.PowerPoint.plist
  6. Restart PowerPoint

13. Check for Conflicting Software

Other applications can interfere with PowerPoint:

  • Screen recording software (OBS, Camtasia)
  • Antivirus programs - temporarily disable to test
  • Display capture software (NVIDIA GeForce Experience, AMD ReLive)
  • System optimizers
  • Bluetooth presentation remotes - unplug and test

14. Reinstall Microsoft Office

⚠️ Important: Before uninstalling, deactivate your Office license if you have a standalone version. Office 365 users can simply reinstall.

Windows

  1. Open Control Panel → Programs → Programs and Features
  2. Right-click Microsoft Office → Uninstall
  3. Follow the uninstall wizard
  4. Restart your computer
  5. Reinstall Office from office.com
  6. Sign in and activate

Mac

  1. Move Microsoft Office folder from Applications to Trash
  2. Empty Trash
  3. Restart Mac
  4. Download Office from office.com or App Store
  5. Install and sign in

Frequently Asked Questions

Why does PowerPoint keep crashing?

PowerPoint crashes are typically caused by corrupted add-ins, large file sizes, corrupted presentation files, or conflicts with other software. Try opening in Safe Mode to diagnose the issue.

How do I recover an unsaved PowerPoint presentation?

File → Info → Manage Workbook → Recover Unsaved Workbooks. Or check: C:\Users\[Username]\AppData\Local\Microsoft\Office\UnsavedFiles on Windows.

Why won't my slides play in presentation mode?

Check these common issues:

  1. Verify you're pressing F5 or using Slide Show → From Beginning
  2. Check Set Up Slide Show settings
  3. Ensure the correct monitor is selected
  4. Try a lower monitor resolution

How do I fix embedded videos not playing?

Try these solutions:

  1. Test the video outside PowerPoint to ensure it works
  2. Check Playback tab → Start settings
  3. Convert video to MP4 format (H.264 codec)
  4. Disable hardware graphics acceleration
  5. Check if PowerPoint has permission to access the file location

What is the maximum file size for PowerPoint?

PowerPoint can handle files up to 100MB in older versions and up to 2GB in Office 365. However, files over 50MB may experience performance issues. Compress media and images for better performance.

Why are animations and transitions not working?

Check:

  1. Transitions tab → ensure a transition is selected
  2. Animations tab → verify animation is applied
  3. Slide Show → Set Up Slide Show → ensure animations are not disabled
  4. Disable hardware graphics acceleration if animations cause crashes

Can I use PowerPoint Online if the desktop app won't open?

Yes, visit office.com and sign in with your Microsoft account to use PowerPoint Online. While it has fewer features, it's a good backup for editing and presenting presentations.

How do I fix the "Out of memory" error?

This error usually occurs when:

  • Your presentation is too large - compress media and reduce image quality
  • You have too many applications open - close other apps
  • Your computer lacks RAM - close unused programs and restart
  • You're using an old PowerPoint version - update to Office 365

Will repairing Office delete my presentations?

No, repairing Office will not delete any of your PowerPoint presentations. It only repairs the Office application files and registry settings. Your documents are safe.

How do I share a presentation if PowerPoint isn't working?

Alternative methods:

  • Save as PDF for sharing
  • Export to video: File → Export → Create a Video
  • Use PowerPoint Online at office.com
  • Use Google Slides or Apple Keynote (convert file if needed)
