Windows Boot Loop? Here's How to Fix It

A Windows boot loop (where the computer keeps restarting before reaching the desktop) is usually caused by a failed update, corrupted boot files, or a bad driver. You can fix it without reinstalling Windows in most cases.
First: Interrupt the boot process 3 times (press power button during Windows logo) to trigger Recovery Mode. This is your gateway to all repair tools.

What Causes a Windows Boot Loop?

Understanding the cause helps you apply the right fix:

  • Failed Windows Update — Most common cause; corrupted update files or incomplete installation
  • Corrupted Boot Files — Essential system files needed for startup are damaged
  • Bad Driver — Newly installed driver (often graphics or storage) is incompatible
  • Hardware Failure — Failing hard drive, RAM, or power supply
  • BIOS/UEFI Issues — Incorrect boot settings or corrupted firmware
  • Malware — Rare but possible; malicious software corrupting system files

Step 1 — Enter Windows Recovery Mode

Windows Recovery Mode is your central hub for troubleshooting boot issues. There are several ways to access it:

Method 1: Interrupt Startup 3 Times

During the restart loop, press the power button as soon as the Windows logo appears to interrupt startup. Do this 3 times. On the 4th attempt, Windows will boot into "Automatic Repair" / "Recovery Mode" automatically.

Method 2: Using USB Recovery Drive

If you can't interrupt the cycle:

  • Create a Windows 10/11 installation USB on another computer
  • Boot from USB (usually press F2, F12, or Del during startup to access boot menu)
  • Choose "Repair your computer" → Troubleshoot → Advanced options

Method 3: Using Windows Installation Media

If you have Windows installation disc or ISO:

  • Boot from the disc/USB
  • Select "Repair your computer"
  • Go to Troubleshoot → Advanced options

Step 2 — Try Automatic Startup Repair

Run Startup Repair

In Recovery → Advanced Options → Startup Repair. Windows will scan and try to fix boot files automatically. This resolves most update-related boot loops.

  • Select your account
  • Enter your password (if required)
  • Wait for the diagnostic to complete
  • Restart your computer

If Startup Repair Fails

If Startup Repair can't fix the issue, try running it again — sometimes it needs multiple attempts. If it still fails, proceed to Safe Mode methods below.

Step 3 — Boot into Safe Mode

Safe Mode loads Windows with minimal drivers and services. If it boots successfully, the problem is software (drivers or apps), not hardware.

Access Safe Mode from Recovery

In Recovery → Advanced Options → Startup Settings → Restart. After restart, press:

  • Press 4 for Safe Mode
  • Press 5 for Safe Mode with Networking

Remove Recent Updates in Safe Mode

In Safe Mode:

  • Settings → Update & Security → Windows Update
  • Click "View update history"
  • Click "Uninstall updates"
  • Select the most recent update and click "Uninstall"
  • Restart computer

Remove Recent Driver in Safe Mode

If a driver is causing the issue:

  • Press Win+X → Device Manager
  • Expand categories (especially Display adapters, Storage controllers)
  • Right-click recently installed drivers
  • Select "Roll Back Driver" or "Uninstall device"
  • Restart computer

Disable Startup Programs in Safe Mode

Third-party startup programs can cause boot issues:

  • Press Ctrl+Shift+Esc to open Task Manager
  • Go to Startup tab
  • Right-click and disable recently added programs
  • Restart normally

Step 4 — System Restore

Restore to a Previous Point

System Restore reverts system changes without deleting personal files:

  • Recovery → Advanced Options → System Restore
  • Select your account and enter password
  • Choose a restore point from before the problem started
  • Click "Scan for affected programs" to see what will change
  • Click "Finish" to begin restore
  • Restart when complete

System Restore doesn't affect personal files, but removes recently installed apps and drivers.

Step 5 — Command Prompt Repairs

Repair Boot Configuration

In Recovery → Advanced Options → Command Prompt. Type these commands one by one:

  • bootrec /fixmbr — Repairs Master Boot Record
  • bootrec /fixboot — Repairs boot sector
  • bootrec /rebuildbcd — Rebuilds Boot Configuration Data
  • chkdsk /r c: — Checks and repairs disk errors
  • Type exit and press Enter
  • Restart your computer

Run Disk Check

Corrupted files on your hard drive can cause boot issues:

  • In Command Prompt, type: sfc /scannow /offbootdir=c:\ /offwindir=c:\windows
  • This runs System File Checker from the recovery environment
  • Wait for completion — may take 30+ minutes
  • Restart after completion

Step 6 — Check Hardware

Memory (RAM) Issues

If boot issues are hardware-related, RAM problems are common:

  • Try booting with only one RAM stick (if you have multiple)
  • Try different RAM slots
  • If you have integrated graphics, try booting without dedicated GPU

Hard Drive Issues

Check if your hard drive is failing:

  • Listen for unusual clicking or grinding sounds
  • In Command Prompt, run: chkdsk /r c:
  • If disk errors are found, consider replacing the drive
  • If using SSD, check for firmware updates

BIOS/UEFI Reset

Resetting BIOS can fix boot issues:

  • Enter BIOS during startup (press F2, Delete, or F12)
  • Look for "Load Setup Defaults" or "Reset to Factory"
  • Save and exit
  • Alternatively, remove CMOS battery for 5 minutes

Last Resort — Reset Windows

Keep Files Option

Reset PC keeps your personal files but reinstalls Windows:

  • Recovery → Advanced Options → Troubleshoot → Reset this PC
  • Choose "Keep my files"
  • Select your account and enter password
  • Choose "Local reinstall" or "Cloud download"
  • Click "Reset" to begin

This takes 30-60 minutes and reinstalls Windows while keeping your documents, pictures, and music.

Clean Install (Complete Reset)

If all else fails:

  • Create Windows installation USB on another computer
  • Boot from USB
  • Select "Custom: Install Windows only (advanced)"
  • Delete all partitions on your main drive
  • Select "Unallocated Space" and click "New"
  • Proceed with installation
  • IMPORTANT: Back up important data first if possible

Recovering Data Before Fixing

Access Files Without Booting

If you need to recover data first:

  • Use Windows installation USB to access Command Prompt
  • Use a Linux live USB to access your files
  • Remove the hard drive and connect to another PC as external drive
  • Use a USB enclosure or SATA adapter

Preventing Future Boot Loops

Best Practices

  • Create a recovery drive — Before problems occur, create a Windows recovery USB
  • Backup regularly — Use File History, OneDrive, or external drive
  • Update carefully — Wait a week after major Windows updates before installing
  • Update drivers from manufacturer — Not Windows Update (can have outdated drivers)
  • Don't shut down during updates — Let updates complete naturally

Frequently Asked Questions

Why is Windows stuck in a boot loop after an update?

Windows updates sometimes install corrupted files or incompatible drivers. Boot into Safe Mode and uninstall the recent update to fix this. Go to Settings → Update & Security → Windows Update → View Update History → Uninstall Updates.

How do I stop the automatic repair loop?

Press and hold the power button to force shutdown during the automatic repair screen. On the next boot, you'll have access to recovery options. Alternatively, boot from Windows installation media to access recovery tools.

Will I lose my files if I reset Windows?

If you choose "Keep my files," your personal files remain. However, installed apps and system settings are reset. It's always best to backup important files before attempting any repairs.

What if none of these fixes work?

If all troubleshooting fails, the issue is likely hardware — either a failing hard drive or motherboard problem. Consider taking your computer to a repair shop for professional diagnosis, or if under warranty, contact your manufacturer.

Can a boot loop cause data loss?

Usually no — the data is still on your hard drive. However, if the drive is failing, continuing to force boot attempts could make recovery harder. If you suspect hard drive failure, remove the drive and connect it to another PC to backup data first.

How long does Startup Repair take?

Startup Repair typically takes 15-45 minutes. It may appear stuck — don't turn off your computer. If it runs for more than 2 hours, the issue likely requires other solutions.
