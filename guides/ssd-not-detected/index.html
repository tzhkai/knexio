SSD Not Detected? Here's How to Fix It

An SSD that doesn't show up is usually a physical connection issue, an unformatted new drive, or a BIOS/driver compatibility problem. The fix depends on whether the SSD appears in BIOS but not Windows, or is missing entirely.
Diagnose first: Enter BIOS (press F2, Del, or F10 at startup) and check if the SSD appears there. If yes, the issue is in Windows. If no, it's a hardware or BIOS issue.

If SSD Is Not Detected in BIOS

Step 1 — Check Physical Connections

Power off and open the case. For SATA SSDs: check both the SATA data cable and SATA power cable are firmly seated. For M.2: remove the SSD, check for bent pins, reinsert firmly, and secure the retaining screw.

Step 2 — Try a Different SATA Port or M.2 Slot

Some SATA ports disable when M.2 slots are occupied (check motherboard manual). Try SATA port 1 directly. For M.2, try a different slot if your board has two.

Step 3 — Check M.2 Key Compatibility

M.2 SSDs come in B-key, M-key, and B+M-key. NVMe SSDs require M-key slots. Check your motherboard manual and SSD specs to confirm compatibility. Some motherboards only support SATA M.2, not NVMe M.2.

Step 4 — Update BIOS

Older BIOS versions may not support newer NVMe SSDs. Download the latest BIOS from your motherboard manufacturer's website and flash it. Do not interrupt this process.

Step 5 — Check BIOS Storage Controller Mode

In BIOS settings, look for SATA Controller Mode. Try switching between AHCI and Intel RST/RAID. NVMe SSDs need the PCIe/NVMe option where available.

If SSD Shows in BIOS but Not Windows

Step 6 — Initialize in Disk Management

Press Win+X → Disk Management. Look for a disk labeled "Unknown" or "Not Initialized" with unallocated space. Right-click it → Initialize Disk → choose GPT (for modern systems) → then right-click the unallocated space → New Simple Volume to format it.

Step 7 — Assign a Drive Letter

If the SSD shows in Disk Management but not File Explorer, it may be missing a drive letter. Right-click the volume → Change Drive Letter and Paths → Add → Assign a letter (e.g., D:).

Step 8 — Update NVMe Drivers

Device Manager → Disk drives → Right-click your SSD → Update driver → Search automatically. For Samsung, WD, or Crucial SSDs, also check their official software (Samsung Magician, WD Dashboard) for driver and firmware updates.

Frequently Asked Questions

Will initializing an SSD erase my data?

Yes. Initializing and formatting erases all data on the drive. Only do this with a new drive or one you don't need data from. If you need data recovery, stop and use recovery software first.
