1. Quick Fixes to Try First

Before advanced troubleshooting

  1. Restart Firefox — close completely and reopen
  2. Restart your computer — clears memory and resets processes
  3. Update Firefox — Menu → Help → About Firefox
  4. Check your internet — try loading sites in another browser
Tip: If Firefox works in Safe Mode, the issue is caused by an add-on or custom setting.

2. Firefox Safe Mode

Safe Mode starts Firefox with all extensions disabled and default settings, helping you diagnose whether the problem is with add-ons or settings.

How to enter Safe Mode

  1. Click the menu button (three horizontal lines)
  2. Click Help and select Troubleshoot Mode...
  3. Click Restart with Add-ons Disabled
  4. When Firefox opens, test if the issue persists

Alternatively, hold Shift

On Windows or Linux, hold Shift while clicking the Firefox icon to launch directly into Safe Mode.

What Safe Mode does

  • Disables all extensions and themes
  • Resets toolbar and button customizations
  • Disables hardware acceleration
  • Uses default theme and content settings

3. Pages Won't Load in Firefox

When Firefox can't load web pages, follow these troubleshooting steps:

Step 1: Clear Cache and Cookies

Clear browsing data

  1. Press Ctrl + Shift + Delete (Windows) or Cmd + Shift + Delete (Mac)
  2. Select Everything as the time range
  3. Check Cache and Cookies
  4. Click Clear Now

Step 2: Flush DNS

  1. Open Command Prompt (Windows) or Terminal (Mac)
  2. Windows: type ipconfig /flushdns and press Enter
  3. Mac: type sudo dscacheutil -flushcache and press Enter
  4. Try loading the page again

Step 3: Check Proxy Settings

  1. Go to Settings → Network Settings
  2. Under Configure Proxy Access to the Internet, select No Proxy or Auto-detect
  3. If you need a proxy, ensure it's configured correctly

Step 4: Check about:networking

  1. Type about:networking in the address bar
  2. Click Flush DNS Cache
  3. Also check the DNS tab to see cached entries

4. Firefox Keeps Crashing

Frequent crashes in Firefox can be caused by add-ons, corrupted profile data, or system issues.

Method 1: Refresh Firefox

Reset Firefox to default settings

  1. Type about:support in the address bar
  2. Click Refresh Firefox (top right)
  3. Confirm by clicking Refresh Firefox again
  4. Firefox will restart with fresh settings but keep your bookmarks

Method 2: Create New Profile

  1. Type about:profiles in the address bar
  2. Click Create New Profile
  3. Follow the wizard to create the profile
  4. Set the new profile as default and launch Firefox with it
  5. If the new profile works, the old profile had issues

Method 3: Disable Hardware Acceleration

  1. Go to Settings → Performance
  2. Uncheck Use recommended performance settings
  3. Uncheck Use hardware acceleration when available
  4. Relaunch Firefox

5. Firefox is Slow

If Firefox runs sluggishly, try these performance optimizations:

Check Resource Usage

  1. Type about:performance in the address bar
  2. Look at the Memory column
  3. Identify tabs or add-ons using excessive resources
  4. Close or remove problematic items

Optimize Firefox Settings

Performance tweaks

  1. Go to Settings → Performance
  2. Enable Reduce tab animations
  3. Limit content processes (recommended: 4-8)
  4. Enable Hardware Acceleration only if your GPU is modern

Manage tabs efficiently

  • Use Tab Groups to organize related tabs
  • Pin frequently used tabs
  • Use the OneTab extension to consolidate tabs
  • Close tabs you're not actively using

6. Firefox Won't Open

If Firefox fails to launch at all, try these solutions:

Method 1: End Firefox Processes

  1. Press Ctrl + Shift + Esc (Windows) or Cmd + Option + Esc (Mac)
  2. Find all Firefox processes
  3. Click End Task (Windows) or Force Quit (Mac)
  4. Try launching Firefox again

Method 2: Run as Administrator (Windows)

  1. Right-click the Firefox shortcut
  2. Select Run as administrator
  3. If it works, right-click again → Properties → Compatibility → check "Run this program as administrator"

Method 3: Reinstall Firefox

Complete reinstall

  1. Uninstall Firefox from Settings → Apps
  2. Delete the Firefox folder in %LOCALAPPDATA%\Mozilla\Firefox
  3. Download the latest Firefox from mozilla.org
  4. Install and sign in to your Firefox Account to restore data

7. Add-On Related Issues

Firefox add-ons (extensions and themes) are a common source of problems.

How to disable add-ons

  1. Type about:addons in the address bar
  2. Click the gear icon and select Manage Extension Shortcuts
  3. Toggle off each extension to test
  4. Common problematic types: ad blockers, VPN add-ons, download managers, old themes
Tip: Only keep add-ons you actively use. Review your add-ons monthly and remove anything you haven't used in 30 days.

8. Firefox on Mobile (Android & iOS)

Android

Fix Firefox on Android

  1. Update Firefox — Play Store → Firefox → Update
  2. Clear cache — Settings → Storage → Clear Cache
  3. Clear data — Settings → Storage → Clear Data (will sign you out)
  4. Restart device — Power button → Restart
  5. Reinstall — Long-press app → Uninstall → reinstall from Play Store

iPhone / iPad

  1. Update Firefox — App Store → Firefox → Update
  2. Force close — Swipe up from bottom → swipe away Firefox card
  3. Clear data — Firefox → Settings → Clear Private Data
  4. Reinstall — Long-press → Remove App → reinstall from App Store
