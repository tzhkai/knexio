Microsoft Outlook is the most widely used email client in business environments. When it fails to open, shows "Disconnected," or stops syncing, it can halt your work. This guide covers every major Outlook fix for Windows, Mac, iPhone, and Android — including login issues, storage problems, rule conflicts, and IMAP setup.

1. Outlook Login & Authentication Issues

If Outlook won't let you sign in or keeps asking for your password:

How to Fix Authentication Problems

  1. Check your Microsoft account — Visit account.microsoft.com to verify your credentials work on the web.
  2. Reset your password — If you've forgotten it, go to account.live.com/password/reset.
  3. Use the correct email format — For Microsoft 365 work accounts, use your full email (). For personal Outlook/Hotmail, use your full address ().
  4. Enable 2-Factor Authentication (2FA) — If 2FA is required by your organization, Outlook may need a sign-in assistant or app password.
  5. Clear credential cache — Go to Windows Control Panel → Credential Manager → Windows Credentials → remove any saved Outlook credentials. Then restart Outlook.
  6. Check for expired password — Corporate Microsoft 365 accounts often require password changes every 90 days. If your password expired, update it and re-enter in Outlook.
  7. Allow less secure sign-ins — For personal Outlook.com accounts without 2FA, you may need to enable "Less secure app access" in your Microsoft account security settings.
Note for Microsoft 365 users: If your admin has enforced Multi-Factor Authentication (MFA) or Conditional Access policies, you may need to register your device through the Microsoft Authenticator app before Outlook will accept your credentials.

2. Outlook Not Opening

If Outlook crashes on launch or freezes on the startup screen:

Step-by-Step Fix

  1. Wait 60 seconds — Outlook can hang at "Loading Profile" on slow computers.
  2. End any existing Outlook processes: Ctrl+Alt+Delete → Task Manager → find Outlook.exe → End Task. Then relaunch.
  3. Launch Outlook in safe mode: hold Ctrl and double-click the Outlook icon. Click Yes when prompted.
  4. If Outlook opens in safe mode, an add-in is the cause (see Safe Mode section below).
  5. Restart your computer and reopen Outlook normally.
  6. Create a new Outlook profile — Control Panel → Mail → Show Profiles → Add → configure your email account → set as default.

3. Outlook Disconnected / Not Connecting to Server

The status bar at the bottom of Outlook shows "Disconnected," "Trying to Connect," or "Working Offline." Here's how to fix it:

  1. Check "Work Offline" mode – Go to Send/Receive tab → make sure "Work Offline" is NOT highlighted. Click it to toggle back online.
  2. Verify internet connection – Open a browser and check connectivity.
  3. Check Microsoft 365 service status – Visit status.office365.com for outage information.
  4. Repair your account – File → Account Settings → Account Settings → select your account → Repair.
  5. Remove and re-add the account – As a last resort, remove your account from Outlook and add it back fresh.
  6. Reset the AutoDiscover feature – Close Outlook. Delete the AutoDiscover registry key: HKEY_CURRENT_USER\Software\Microsoft\Office\XX.0\Outlook\AutoDiscover. Relaunch Outlook.
Tip: Press F9 or go to Send/Receive → Send/Receive All Folders to manually force Outlook to sync.

4. Emails Not Syncing

Missing new emails, items stuck in Outbox, or sent items not appearing:

  1. Press F9 to manually trigger send/receive.
  2. Check your mailbox size — many corporate Exchange accounts have quotas. A full mailbox blocks incoming mail.
  3. Repair the OST data file – Close Outlook. In Windows, search "scanpst.exe" (Inbox Repair Tool) and run it against your OST/PST file. This fixes corruption.
  4. Delete and recreate the email account profile in Outlook.
  5. Clear the Outlook cache – Close Outlook. Navigate to %localappdata%\Microsoft\Outlook\RoamCache and delete all files. Relaunch Outlook.
  6. Check folder sync settings – Right-click any folder → IMAP Folders → make sure all folders are set to subscribe/sync.
Warning: Before running SCANPST or deleting your profile, back up your PST/OST file. Default location: C:\Users\[username]\AppData\Local\Microsoft\Outlook\

5. Mailbox Full / Storage Issues

If Outlook is slow, crashes frequently, or won't receive new emails, your mailbox may be full:

  1. Check mailbox size – Right-click your mailbox root → Data File Properties → Folder Size → Advanced. Most Exchange/Microsoft 365 accounts have 50 GB–100 GB limits.
  2. Empty Deleted Items automatically – File → Options → Advanced → AutoArchive → enable AutoArchive. Set it to run daily and delete items older than 30 days.
  3. Manually archive old emails – File → Options → Advanced → AutoArchive Settings → Archive this folder automatically → select folders.
  4. Compress the PST file – File → Account Settings → Account Settings → Data Files → Settings → Compact Now. This reduces PST file size.
  5. Delete large attachments – Search for emails with large attachments, then remove attachments from messages (Edit → Remove Attachment) or delete the emails.
  6. Use Outlook.com storage management – If using Outlook.com, visit outlook.live.com/storage to purchase additional storage or free up space.
Tip: For PST files over 50 GB, consider splitting into multiple PST files using the Outlook Import/Export wizard. Large PST files can cause performance issues and corruption.

6. Outlook Rules & Filter Problems

If your Outlook rules (also called "rules") are not running correctly:

Common Rule Issues and Fixes

  1. Rules disabled – Rules may have been accidentally turned off. Go to File → Manage Rules & Alerts. Ensure all rules are checked/enabled.
  2. Rule conflicts – If two rules target the same emails, they may cancel each other out. Reorder rules by importance: Rules → Manage Rules & Alerts → drag to reorder.
  3. Rules only apply on send/receive – Server-side rules (Exchange/Microsoft 365) run automatically. Client-side rules (POP/IMAP) only run when Outlook is open.
  4. Rule actions are ignored – If a rule says "stop processing more rules," subsequent rules won't run. Uncheck this option if not intended.
  5. Rule condition not matching – Check that your rule conditions are specific enough. For example, "from contains john" also matches "" — use exact match if needed.
  6. Too many rules – Having 50+ rules can slow Outlook significantly. Consolidate similar rules or archive rarely-used ones.
  7. Rules not working on mobile – Rules only run on the device/client where they are created. For server-side rules, they apply everywhere, but only on Microsoft 365/Exchange accounts.

How to Check and Fix Your Rules

  1. Go to File → Manage Rules & Alerts.
  2. Review all rules listed. Enabled rules have a checkmark.
  3. Click Options to see a detailed view of rule conditions and actions.
  4. To reorder rules, select a rule and click Move Up or Move Down.
  5. To test a rule, manually run it: click Run Rules Now → select the rule → select folders → Run Now.
  6. Delete and recreate problematic rules rather than trying to edit complex ones.
Note: If using a shared mailbox or delegated account, rules created in those mailboxes must be stored in the delegate's Outlook, not the shared mailbox itself.

7. Safe Mode & Disabling Add-ins

Add-ins (plugins) are a common cause of Outlook crashes and slowness. Safe mode disables all add-ins temporarily:

  1. Open Outlook in safe mode: hold Ctrl and click the Outlook icon.
  2. If Outlook works normally in safe mode, go to: File → Options → Add-ins.
  3. At the bottom, in the "Manage" dropdown select "COM Add-ins" → Go.
  4. Uncheck all add-ins and click OK.
  5. Close and reopen Outlook normally. Re-enable add-ins one at a time to identify the problematic one.
  6. Update or remove problematic add-ins — Visit the add-in manufacturer's website for updates.

8. Repair Microsoft Outlook (Windows)

The built-in Office repair tool can fix most Outlook problems without uninstalling:

  1. Close Outlook completely.
  2. Open Control Panel → Programs → Programs and Features.
  3. Find "Microsoft Office" or "Microsoft 365" in the list → click Change.
  4. Select Quick Repair first (no internet needed, takes ~5 min).
  5. If Quick Repair doesn't help, run Online Repair (requires internet, ~30 min, more thorough).
Mac users: Run Microsoft AutoUpdate from the Applications folder. If that doesn't help, use Finder → Applications → Microsoft Outlook → right-click → Show Package Contents → Office365RepairTool (if available).

9. Outlook Mobile App Not Working

iPhone Fixes

  1. Force-close the Outlook app and reopen.
  2. Update Outlook from the App Store.
  3. Go to Settings → Outlook → toggle Background App Refresh on.
  4. Remove your account inside Outlook (tap your avatar → settings icon → account → Delete Account) and re-add it.
  5. Delete and reinstall the Outlook app.
  6. Check Focus/DND settings — iOS Focus mode can block Outlook notifications. Add Outlook to Focus exceptions.
  7. Clear credentials — Settings → Outlook → Account → Reset Account. This forces a full re-authentication.

Android Fixes

  1. Clear Outlook app cache: Settings → Apps → Outlook → Storage → Clear Cache.
  2. Update Outlook from Google Play.
  3. Disable battery optimization for Outlook: Settings → Battery → Battery Optimization → Outlook → Don't optimize.
  4. Remove and re-add your account in the Outlook app.
  5. Check app permissions — Settings → Apps → Outlook → Permissions → ensure Notifications, Storage, and Contacts are allowed.
  6. Try Samsung-specific fix — If on Samsung devices, also check Settings → Device Care → Battery → Apps → Outlook → Allow background activity.

10. Outlook on the Web (OWA) Not Working

If outlook.live.com or your company's OWA fails to load:

  1. Clear browser cache (Ctrl+Shift+Delete in Chrome).
  2. Try Incognito/Private mode to rule out extension conflicts.
  3. Use the light version of OWA: add ?light=1 to the URL.
  4. Try a different browser.
  5. Check status.office365.com for Microsoft 365 service issues.
  6. Allow cookies — OWA requires cookies for authentication. Ensure third-party cookies are not fully blocked.
  7. Check your organization's network policy — Corporate firewalls may block OWA. Contact your IT department.

11. Outlook IMAP & POP Settings

Use these settings if you're setting up Outlook with a non-Exchange email account (e.g., Gmail, Yahoo, or a generic IMAP provider):

IMAP Settings (Recommended for most accounts)

  • Incoming Email Server (IMAP): imap-mail.outlook.com
  • Port: 993 (SSL/TLS encrypted)
  • Outgoing Email Server (SMTP): smtp-mail.outlook.com
  • SMTP Port: 587 (TLS/STARTTLS)
  • Username: Your full email address
  • Password: Your email password OR an App Password (for accounts with 2FA)
  • Authentication: Choose "Normal Password" or "OAuth2" depending on your provider.

POP Settings

  • Incoming Email Server (POP): pop-mail.outlook.com
  • Port: 995 (SSL encrypted)
  • SMTP Server: smtp-mail.outlook.com
  • SMTP Port: 587
  • Leave a copy of messages on server: Check this if you want to access the same mail from multiple devices.

Microsoft 365 / Exchange Settings

  • Server: outlook.office365.com
  • Port: 993 (IMAP with SSL) or 995 (POP with SSL)
  • SMTP: smtp.office365.com on port 587 (TLS)
  • Authentication: Modern Authentication (OAuth 2.0) is recommended. Your admin may require this.
Tip: To add an IMAP account in Outlook: File → Add Account → enter your email address → Advanced options → choose IMAP. Outlook will auto-detect most settings for popular email providers.
OAuth2 is recommended: Avoid using basic authentication (username + password) for IMAP/SMTP if your provider supports OAuth 2.0. OAuth is more secure and isn't blocked by Microsoft's security policies in Microsoft 365.
