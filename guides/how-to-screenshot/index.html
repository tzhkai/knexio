How to Take a Screenshot

Quick shortcuts for every device and OS

Ad space

Windows

Win + Shift + S
Snipping Tool — select area
Win + PrtScn
Full screen → Pictures/Screenshots
PrtScn
Full screen to clipboard
Alt + PrtScn
Active window to clipboard

Mac

Cmd + Shift + 3
Full screen screenshot
Cmd + Shift + 4
Select area to screenshot
Cmd + Shift + 4 + Space
Screenshot a window
Cmd + Shift + 5
Screenshot toolbar (macOS Mojave+)

Screenshots save to Desktop by default.

iPhone

  • Face ID models: Press Side button + Volume Up simultaneously
  • Home button models: Press Side/Top button + Home button
  • Screenshot appears in Photos → Recents

Android

  • Press Power + Volume Down simultaneously
  • Some devices: swipe palm across screen
  • Saved to Gallery → Screenshots

Chromebook

  • Full screen: Ctrl + Show Windows (F5 key)
  • Partial: Ctrl + Shift + Show Windows
  • Saved to Downloads folder

Frequently Asked Questions

Where are screenshots saved?

Windows: Pictures/Screenshots. Mac: Desktop. iPhone/Android: Photos/Gallery. Chromebook: Downloads.

How do I screenshot a scrolling page?

Use browser extensions like GoFullPage (Chrome) or use our Website Screenshot tool.
