USB Not Recognized? Here's How to Fix It

When Windows shows "USB device not recognized" or a USB drive simply doesn't appear, it's usually a driver, power, or file system issue — not a permanently broken device. Here's how to diagnose and fix it.
First step: Try a different USB port and a different computer. This tells you whether the problem is with the port, the cable, or the USB device itself.

Fixes for Windows

Step 1 — Try Different Ports and Cables

Plug the USB device into a different port. If using USB-C, try a different cable. Avoid USB hubs for initial testing — connect directly.

Step 2 — Check Device Manager

Right-click Start → Device Manager → Look for yellow warning icons under Universal Serial Bus Controllers or Other Devices. Right-click → Update Driver or Uninstall Device → scan for hardware changes.

Step 3 — Reinstall USB Controllers

In Device Manager → Universal Serial Bus Controllers → Right-click each item → Uninstall → Restart PC. Windows will automatically reinstall them on reboot.

Step 4 — Disable USB Selective Suspend

Control Panel → Power Options → Change plan settings → Change advanced power settings → USB Settings → USB Selective Suspend Setting → Set to Disabled.

Step 5 — Check Disk Management (for USB drives)

Press Win+X → Disk Management. If your USB drive appears here without a drive letter: right-click → Change Drive Letter → Assign a letter. If it says "Not Initialized," right-click → Initialize Disk (this will erase data).

Step 6 — Update Windows

Settings → Windows Update → Check for updates. Some USB recognition issues are resolved in Windows patches.

Fixes for Mac

Step 1 — Check Finder Preferences

Finder → Preferences → General → Ensure "External disks" is checked under "Show these items on the desktop."

Step 2 — Check Disk Utility

Open Disk Utility (Spotlight → "Disk Utility"). If the drive appears but is grayed out: select it → click Mount. If it shows errors: click First Aid.

Step 3 — Reset SMC

Resetting the SMC on Intel Macs can fix USB port power issues. Shut down → Hold Shift+Control+Option+Power for 10 seconds → Release → Power on.

Frequently Asked Questions

Why does USB work on one port but not another?

Individual USB ports can fail due to physical damage or driver issues. If only one port doesn't work, it may need hardware repair.

Can a USB hub cause recognition issues?

Yes, especially unpowered hubs. High-power devices like external drives need a powered USB hub or direct connection to the computer.
