Keyboard Not Working? Here's How to Fix It

A non-responsive keyboard is usually caused by a software issue — a corrupted driver, an accidental accessibility setting, or a stuck system process. Hardware failure is less common. Start with these software fixes.
Use On-Screen Keyboard: Press Win+Ctrl+O or search "On-Screen Keyboard" in Start Menu to type while you fix the hardware keyboard.

Fixes for Windows

Step 1 — Check Filter Keys

Filter Keys is a Windows accessibility feature that ignores brief keystrokes. If accidentally enabled, it makes the keyboard seem broken. Go to Settings → Accessibility → Keyboard → Make sure Filter Keys is Off.

Step 2 — Check Connection (External Keyboards)

For USB keyboards: Unplug and replug into a different USB port. For Bluetooth: Go to Settings → Bluetooth → Remove the keyboard → Re-pair it.

Step 3 — Reinstall Keyboard Driver

Device Manager → Keyboards → Right-click your keyboard → Uninstall device → Restart PC. Windows will automatically reinstall the correct driver.

Step 4 — Run Keyboard Troubleshooter

Settings → System → Troubleshoot → Other troubleshooters → Keyboard → Run.

Step 5 — Check for Windows Updates

Settings → Windows Update → Check for updates. Driver issues introduced by updates are sometimes fixed in subsequent patches.

Step 6 — Boot in Safe Mode

If keyboard works in Safe Mode but not normally, a third-party program is interfering. Boot normally and disable startup programs via Task Manager.

Fixes for Mac

Step 1 — Check Slow Keys

System Settings → Accessibility → Keyboard → Turn off Slow Keys. This setting makes the Mac wait before registering a keypress, appearing as broken.

Step 2 — Reset NVRAM

Shut down → hold Option+Command+P+R at startup for 20 seconds. NVRAM stores keyboard settings and resetting can fix layout issues.

Step 3 — Delete Keyboard Preference File

Go to ~/Library/Preferences → Delete com.apple.keyboardtype.plist → Restart. Mac will recreate the file with defaults.

Frequently Asked Questions

Why is only part of my keyboard working?

If only some keys work, clean under the non-functional keycaps with compressed air. Dirt and debris is a common cause. For liquid damage, let the keyboard dry completely (24-48 hours) before testing again.
