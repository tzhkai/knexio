Keyboard Not Working? Here's How to Fix It

A non-responsive keyboard is usually caused by a software issue — a corrupted driver, an accidental accessibility setting, or a stuck system process. Hardware failure is less common. Start with these software fixes.
Use On-Screen Keyboard: Press Win+Ctrl+O or search "On-Screen Keyboard" in Start Menu to type while you fix the hardware keyboard.

Common Keyboard Problems

Before diving into fixes, identify which issue you're experiencing:

  • Entire keyboard not working — Usually a connection or driver issue
  • Some keys not working — Often debris or hardware damage
  • Keys typing wrong characters — Language or layout settings issue
  • Laptop keyboard not working — May need function key (Fn) combination
  • Wireless keyboard not connecting — Battery or pairing issues

Fixes for Windows

Step 1 — Check Filter Keys

Filter Keys is a Windows accessibility feature that ignores brief keystrokes. If accidentally enabled, it makes the keyboard seem broken.

  • Go to Settings → Accessibility → Keyboard
  • Make sure "Filter Keys" is turned OFF
  • Also check "Sticky Keys" and "Toggle Keys" — turn these OFF too

Quick check: Press and hold the right Shift key for 8 seconds to see if a dialog appears about Filter Keys.

Step 2 — Check Connection (External Keyboards)

For USB keyboards:

  • Unplug and replug the keyboard into a different USB port
  • Try a USB port on the back of your computer instead of the front
  • If using a USB hub, try connecting directly to the computer

For Bluetooth keyboards:

  • Go to Settings → Bluetooth → Remove the keyboard
  • Put your keyboard in pairing mode (check the manual)
  • Re-pair the keyboard
  • Make sure Bluetooth is enabled on your PC

Step 3 — Reinstall Keyboard Driver

Corrupted or outdated drivers can cause keyboard issues:

  • Press Win+X → Device Manager
  • Expand "Keyboards" category
  • Right-click your keyboard (usually "Standard PS/2 Keyboard" or HID Keyboard Device)
  • Select "Uninstall device"
  • Restart your PC — Windows will automatically reinstall the correct driver

Step 4 — Run Keyboard Troubleshooter

Windows has a built-in troubleshooter:

  • Go to Settings → System → Troubleshoot
  • Click "Other troubleshooters"
  • Find "Keyboard" and click "Run"
  • Follow the on-screen instructions

Step 5 — Check for Windows Updates

Sometimes keyboard issues are caused by bugs that get fixed in updates:

  • Go to Settings → Windows Update
  • Click "Check for updates"
  • Install any available updates
  • Restart your computer if prompted

Step 6 — Boot in Safe Mode

If your keyboard works in Safe Mode but not normally, a third-party program is interfering:

  • Boot into Safe Mode: Press Win+I during startup or use System Configuration (msconfig)
  • If keyboard works in Safe Mode, the issue is software
  • Disable startup programs via Task Manager → Startup tab
  • Try disabling recently installed software

Step 7 — Check BIOS Settings

Sometimes keyboard settings in BIOS get changed:

  • Restart your computer and enter BIOS (press F2, Delete, or F12 during boot)
  • Look for "USB Keyboard Support" or "PS/2 Keyboard Support" in settings
  • Ensure it's enabled
  • Exit and save changes

Step 8 — Check for Hardware Issues

Test if your keyboard works on another computer or if another keyboard works on your computer:

  • Try your keyboard on another PC/laptop
  • If it works elsewhere, the issue is your computer's ports or software
  • If another keyboard works on your PC, your keyboard may be faulty

Fixes for Mac

Step 1 — Check Slow Keys

Mac's accessibility features can make keyboards appear broken:

  • Go to System Settings → Accessibility → Keyboard
  • Turn OFF "Slow Keys"
  • Also check "Sticky Keys" and turn it OFF if enabled

Step 2 — Reset NVRAM

NVRAM stores keyboard-related settings. Resetting can fix persistent issues:

  • Shut down your Mac
  • Press the power button, then immediately hold Option + Command + P + R
  • Hold for about 20 seconds until you hear the startup sound twice
  • Let go and let your Mac boot normally

Step 3 — Delete Keyboard Preference File

Corrupted preferences can cause keyboard issues:

  • Go to ~/Library/Preferences
  • Find and delete com.apple.keyboardtype.plist
  • Restart your Mac — it will recreate the file with defaults

Step 4 — Check Keyboard Language Settings

Wrong keyboard layout can cause typing issues:

  • Go to System Settings → Keyboard → Input Sources
  • Ensure only the keyboards you use are listed
  • Remove any unfamiliar keyboards
  • Make sure "Show Input menu in menu bar" is checked

Step 5 — Reset SMC (for MacBooks)

The System Management Controller handles keyboard power:

  • Shut down your Mac
  • Press Control + Option + Shift + Power button
  • Hold for 10 seconds
  • Press Power again to turn on

Laptop-Specific Fixes

Laptop Keyboard Not Working

If your laptop's built-in keyboard isn't working:

  • Check Fn key lock — Some laptops have an Fn lock (usually Fn+Esc or a dedicated key)
  • Try external keyboard — If external works, the laptop keyboard may be damaged
  • Check function keys — Some keys work only with Fn held
  • Update touchpad driver — Sometimes touchpad drivers affect keyboard
  • Check for physical damage — Inspect for spills or damage

Keyboard Backlight Not Working

For laptops with backlit keyboards:

  • Check function key combination (often Fn + F5/F6/F7 or a dedicated key)
  • Update keyboard/fn+ driver from manufacturer website
  • Check BIOS settings for keyboard backlight options
  • On Dell: Open Dell SupportAssist or BIOS
  • On HP: Open HP Support Assistant
  • On Lenovo: Use Vantage or ThinkPad Settings

Wireless Keyboard Fixes

Wireless Keyboard Not Connecting

For Bluetooth and RF wireless keyboards:

  • Check batteries — Replace with fresh batteries
  • Check pairing — Re-pair the keyboard to your computer
  • Check USB receiver — For RF keyboards, try a different USB port
  • Check for interference — Move away from other wireless devices
  • Check distance — Keep keyboard within 10 feet of the receiver

Specific Keyboard Problems

Some Keys Not Working

If only specific keys don't respond:

  • Clean under the keys — Use compressed air to blow out debris
  • Check for liquid damage — If exposed to liquid, let dry 24-48 hours
  • Test the keys — Use an online keyboard tester to identify which keys are dead
  • Physical damage — Dropped keyboards often have broken key switches

Keys Typing Wrong Characters

If keys produce unexpected output:

  • Check language settings — Windows: Settings → Time & Language → Language → Language options
  • Check keyboard layout — Make sure it's set to your region (US, UK, etc.)
  • Switch keyboard — Press Win+Space (Windows) or Cmd+Space (Mac) to switch layouts

Spacebar or Enter Not Working

Common problem keys that get heavy use:

  • Clean around these keys — they get more debris
  • Try cleaning with isopropyl alcohol on a cotton swab
  • Check if the keycap is loose or misaligned
  • If software fixes don't work, the key switch may need replacement

Frequently Asked Questions

Why is only part of my keyboard working?

If only some keys work, clean under the non-functional keycaps with compressed air. Dirt and debris is a common cause. For liquid damage, let the keyboard dry completely (24-48 hours) before testing again.

Why does my laptop keyboard stop working when I plug in a USB keyboard?

This is usually a driver conflict. Try plugging in the USB keyboard before your laptop boots, or update both keyboard drivers. Some laptops automatically disable the built-in keyboard when external input is detected.

How do I type if my keyboard isn't working?

Use the on-screen keyboard: Press Win+Ctrl+O (Windows) or click the Input menu in the menu bar → Show Keyboard Viewer (Mac). You can also use voice typing: Win+H (Windows) or Cmd+Shift+Space (Mac).

Can a virus cause keyboard issues?

Yes, some malware can interfere with input devices. Run a full antivirus scan to check for infections. If your keyboard works in Safe Mode but not normally, malware is likely the cause.

Why do certain keys type numbers instead of letters?

Num Lock is likely enabled. Press the Num Lock key to turn it off. On some laptops, you may need to press Fn+Num Lock.

Should I replace my keyboard or buy a new computer?

If the keyboard is built into your laptop and other fixes haven't worked, consider professional repair or an external keyboard. For desktop keyboards, they're usually replaceable. Weigh the cost of repair vs. replacement.
