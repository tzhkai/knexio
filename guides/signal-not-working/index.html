Signal prioritizes privacy and security. When it stops working, here's how to troubleshoot.

Signal Audio/Video Call Troubleshooting

Signal supports encrypted voice and video calls. Here's how to fix common issues:

Voice Calls Not Connecting

  1. Check your internet connection (calls require stable data)
  2. Ensure Signal has microphone permission in device settings
  3. Switch between Wi-Fi and mobile data
  4. Check if the recipient has notifications on
  5. Try calling again after a minute

Video Calls Not Working

  1. Tap the video icon to start a video call
  2. Verify camera permission is granted to Signal
  3. Close other apps using the camera
  4. Check internet speed (video calls need 1+ Mbps)
  5. Switch to audio call and back to video

Call Quality Issues

  • Use Wi-Fi for better quality, or mobile data if Wi-Fi is weak
  • Move to an area with better signal
  • Close other apps using bandwidth
  • Try using headphones

Signal Connection & Firewall Issues

Network problems can prevent Signal from connecting:

Network Restrictions

  1. Check if other apps work on your network
  2. Toggle airplane mode on/off to reset connection
  3. Switch between Wi-Fi and mobile data
  4. Try using a VPN to test if network is blocking Signal

Firewall Configuration

Some networks block Signal's connections:

  • Corporate networks may block Signal
  • Contact IT to allow Signal domains and ports
  • Signal uses: TCP 443, UDP 3478
  • Try mobile data if Wi-Fi is restricted

Battery Optimization

Battery savers can prevent Signal from working properly:

  1. Android: Settings → Apps → Signal → Battery → Unrestricted
  2. iOS: Settings → Signal → disable Low Power Mode
  3. Disable battery optimization for Signal
  4. Allow background activity

Signal Login Problems

Verification Code Not Received

  1. Ensure your phone can receive SMS and calls
  2. Check your phone number is correct (include country code)
  3. Wait a few minutes (rate limiting)
  4. Try "Call me" instead of SMS
  5. Ensure you're not in airplane mode

Re-registering Signal

If you need to register with the same number:

  1. Open Signal → Settings → Account
  2. Tap "Delete Account" (this erases all messages)
  3. Reinstall Signal or tap "Re-register"
  4. Enter your phone number and verify
  5. Restore from backup if available

Linked Devices Issues

  • Go to Settings → Linked Devices
  • Remove old/unused device links
  • Re-scan QR code to re-link devices
  • Ensure both devices have recent Signal versions

Signal Update Procedures

Update on Mobile

  1. iOS: App Store → Search Signal → Update
  2. Android: Play Store → Search Signal → Update
  3. Enable auto-updates in your app store
  4. Always update to the latest version for security

Update on Desktop

  1. Open Signal Desktop
  2. Check for updates in the app or download from signal.org
  3. Ensure your phone has the latest Signal version too

Signal Cache Clearing Steps

Clearing cache can fix issues but doesn't delete messages:

Clear Cache on Android

  1. Go to Settings → Apps → Signal → Storage
  2. Tap "Clear Cache"
  3. Note: Clearing storage will delete messages unless backed up

Clear Cache on iOS

iOS doesn't allow per-app cache clearing:

  1. Delete the Signal app
  2. Reinstall from App Store
  3. Messages are stored locally, so back up first

Clear Cache on Desktop

  1. Close Signal Desktop
  2. Windows: %AppData%\Signal
  3. macOS: ~/Library/Application Support/Signal
  4. Delete Cache folder only
  5. Restart Signal

1. Signal Not Sending Messages

  1. Check your internet connection works in other apps.
  2. Verify your phone number is still active and can receive SMS.
  3. Ensure Signal has permission to send SMS (Settings → Apps → Signal → Permissions).
  4. Re-register Signal: Settings → Account → Delete Account → Re-register with your number.

2. Signal Calls Not Working

For voice/video call issues:

  • Allow microphone and camera permissions.
  • Check if your firewall blocks Signal.
  • Try switching between Wi-Fi and mobile data.
  • Disable battery saver mode.

3. Signal Keeps Crashing

  1. Update Signal to the latest version.
  2. Clear app cache: Settings → Apps → Signal → Storage → Clear Cache.
  3. Restart your device.
  4. Reinstall Signal if problems persist.
Important: Before reinstalling, ensure you have a backup of your messages as Signal stores them locally.
