Signal Not Working? How to Fix Signal Messenger Problems

Signal prioritizes privacy and security. When it stops working, here's how to troubleshoot.

Common Causes of Signal Problems

  • Network connectivity issues: Poor Wi-Fi or mobile data signal
  • Outdated app version: Older versions may have bugs
  • Battery optimization restrictions: Phone killing Signal in background
  • Permission issues: Missing microphone, camera, or notification permissions
  • Account registration problems: SMS verification not arriving
  • VPN or firewall blocking: Network restrictions

Fix 1: Signal Not Sending Messages

If messages won't send or get stuck:

  1. Check your internet connection by loading a webpage or using another app
  2. Verify your phone number is correct and includes your country code (e.g., +1 for US)
  3. Ensure Signal has permission to send SMS in device settings
  4. Toggle airplane mode on and off to reset the network connection
  5. Restart Signal or your device
  6. If still failing, try re-registering Signal: Settings → Account → Delete Account → Re-register

Fix 2: Audio/Video Call Troubleshooting

Signal supports encrypted voice and video calls. Here's how to fix common issues:

Voice Calls Not Connecting

  1. Check your internet connection (calls require stable data, not just SMS)
  2. Ensure Signal has microphone permission in device settings
  3. Go to Signal Settings → Privacy → verify "Voice & Video" is enabled
  4. Switch between Wi-Fi and mobile data
  5. Check if the recipient has notifications enabled for Signal
  6. Try calling again after a minute

Video Calls Not Working

  1. Tap the video icon to start a video call
  2. Verify camera permission is granted to Signal
  3. Close other apps using the camera (Snapchat, Instagram, other video apps)
  4. Check internet speed (video calls need at least 1 Mbps)
  5. Switch to audio call first, then try adding video back
  6. Ensure both parties have the latest Signal version

Call Quality Issues

  • Use Wi-Fi for better quality, or mobile data if Wi-Fi is weak
  • Move to an area with better cellular signal
  • Close other apps using bandwidth (streaming, downloads)
  • Try using headphones with a built-in mic
  • Turn off video and use voice only on poor connections

Fix 3: Connection & Network Issues

Network problems can prevent Signal from connecting:

Network Restrictions

  1. Check if other apps work on your network
  2. Toggle airplane mode on/off to reset connection
  3. Switch between Wi-Fi and mobile data
  4. Try using a VPN to test if your network is blocking Signal
  5. Check if you're on a corporate or school network that may restrict apps

Firewall Configuration

Some networks block Signal's connections:

  • Corporate networks may block Signal
  • Contact your IT department to allow Signal domains and ports
  • Signal uses: TCP 443, UDP 3478 for calls
  • Try mobile data if Wi-Fi is restricted

Battery Optimization (Important!)

Battery savers can prevent Signal from working properly in the background:

  1. Android: Settings → Apps → Signal → Battery → Select "Unrestricted" or disable battery optimization
  2. iOS: Settings → Signal → Disable Low Power Mode
  3. Disable battery optimization for Signal specifically
  4. Allow Signal to run in background (Settings → Apps → Signal → Battery → Background activity)
  5. On Android, also check: Settings → Battery → Background limits → Remove Signal from restrictions

Fix 4: Registration & Login Problems

Verification Code Not Received

  1. Ensure your phone can receive SMS and calls
  2. Check your phone number is correct (include country code, no dashes)
  3. Wait a few minutes — there may be rate limiting on first-time registration
  4. Try "Call me" instead of SMS option
  5. Ensure you're not in airplane mode
  6. Check that your SIM is active and has SMS capability

Re-registering Signal

If you need to register with the same number again:

  1. Open Signal → Settings → Account
  2. Tap "Delete Account" (warning: this erases all messages)
  3. Reinstall Signal or tap "Re-register" if available
  4. Enter your phone number and verify
  5. Restore from backup if you set one up

Linked Devices Issues

  • Go to Settings → Linked Devices
  • Remove old/unused device links
  • Re-scan QR code to re-link devices
  • Ensure both devices have recent Signal versions
  • Make sure the primary device is connected to the internet

Fix 5: Update Procedures

Update on Mobile

  1. iOS: App Store → Search Signal → Update
  2. Android: Play Store → Search Signal → Update
  3. Enable auto-updates in your app store settings
  4. Always update to the latest version for security and bug fixes

Update on Desktop

  1. Open Signal Desktop
  2. Click the three dots menu → Settings → Check for updates
  3. Or download from signal.org
  4. Ensure your phone has the latest Signal version too

Fix 6: Cache Clearing

Clearing cache can fix issues but doesn't delete messages:

Clear Cache on Android

  1. Go to Settings → Apps → Signal → Storage
  2. Tap "Clear Cache" (this removes temporary files)
  3. Note: Clearing storage will delete messages unless you have a backup

Clear Cache on iOS

iOS doesn't allow per-app cache clearing:

  1. Delete the Signal app
  2. Reinstall from App Store
  3. Messages are stored locally, so back up first if possible

Clear Cache on Desktop

  1. Close Signal Desktop
  2. Windows: %AppData%\Signal
  3. macOS: ~/Library/Application Support/Signal
  4. Delete the "Cache" folder only
  5. Restart Signal

Fix 7: Notifications Not Working

  1. Check that Signal notifications are enabled in device settings
  2. Check if Do Not Disturb or Focus mode is on
  3. Make sure battery optimization isn't blocking Signal
  4. Check Signal Settings → Notifications → make sure they're enabled
  5. On Android, go to Settings → Apps → Signal → Notifications → make sure "Show" is enabled
Important: Before reinstalling, ensure you have a backup of your messages. Signal stores messages locally by default, but you can enable cloud backup in Settings → Chat backup.

Frequently Asked Questions

Why are my Signal messages not delivering?

Messages may show only one check mark if the recipient's phone is off or has no internet connection. Wait for them to come online, or check your own internet connection.

Can I use Signal on multiple devices?

Yes, Signal supports linking up to 4 devices. Go to Settings → Linked Devices → Link New Device. Your primary device must be connected for linked devices to work.

Why does Signal need so many permissions?

Signal needs camera and microphone for video/voice calls, contacts to help you find friends, and storage to send/receive files. You can deny some permissions if not using those features.

Is Signal down right now?

Check Signal's status page at status.signal.org or downdetector.com/signal to see if there are widespread issues.

How do I backup my Signal messages?

Go to Settings → Chat and settings → Chat backup → Enable. On Android, you can set up Google Drive backup; on iOS, use iCloud backup.
