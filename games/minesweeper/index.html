🎮 How to Play Minesweeper

Game Description

Minesweeper is the classic logic puzzle. Clear the board without detonating any mines. Use number clues to identify safe squares!

How to Play

  1. Click a square to reveal what's underneath
  2. Numbers show how many mines touch that square
  3. Right-click to flag suspected mine locations
  4. Clear all safe squares to win
  5. Hit a mine and the game is over
  6. First click is always safe - use it wisely!

Pro Tips & Strategies

  • ✓ Start with corners and edges for better odds
  • ✓ If a 1 touches only one unrevealed square, that square is a mine
  • ✓ If a number equals its adjacent flags, all other adjacent squares are safe
  • ✓ Use double-clicks (if available) to reveal adjacent safe squares
