🎮 How to Play Minesweeper

Game Description

Minesweeper is a classic puzzle game. Uncover cells on a grid while avoiding hidden mines. Use numbers to deduce where mines are located!

Basic Rules & Controls

  1. Click to reveal a cell (may contain a mine!)
  2. Numbers show how many mines are in adjacent cells
  3. Right-click to flag suspected mines
  4. Clear all non-mine cells to win

Pro Tips

  • Start from corners for safer openings
  • If a number equals its unrevealed neighbors, they're all mines
  • Use logic, not guessing—except when forced!

How to Play

Click a cell on the grid to reveal it. Numbers tell you how many mines are adjacent to that cell. Use these number clues to deduce which cells are safe and which hide mines. Right-click or long-press to flag a cell you suspect contains a mine. Reveal all safe cells without detonating a mine to win.

Tips & Strategy

  • Start from the corners — Corner cells have fewer neighbors, so the numbers are simpler to interpret. A corner showing 1 means exactly one of the three adjacent cells is a mine.
  • Use flagging to track deductions — When a number matches the count of unrevealed cells around it, flag them all. Then clear the safe neighbors with confidence.
