🎮 How to Play Puzzle Slide

Game Description

Puzzle Slide is a classic 15-puzzle game. Slide numbered tiles to arrange them in order. Test your logic and planning skills!

Basic Rules & Controls

  1. Click a tile adjacent to the empty space to slide it
  2. Arrange all numbers in order (1-15, empty space last)
  3. Only tiles next to the empty space can move
  4. Fewer moves = better score

Pro Tips

  • Solve the top row first, then work down
  • Don't break completed sections
  • Plan several moves ahead
