🎮 How to Play Falling Blocks

Game Description

Falling Blocks is a fast-paced puzzle game. Move and rotate falling shapes to create complete horizontal lines. Clear lines to score points and keep the board from overflowing!

Basic Rules & Controls

  1. Use arrow keys to move and rotate falling blocks
  2. Complete horizontal lines to clear them
  3. Cleared lines give points; multiple lines = bonus
  4. Game ends when blocks reach the top

Pro Tips

  • Plan ahead—see which piece is coming next
  • Keep the board flat; avoid creating gaps
  • Save space for long I-pieces to clear 4 lines at once
