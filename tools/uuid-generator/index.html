UUID Versions Explained

UUID v1: Generated from the current timestamp and the machine's MAC address. Time-ordered and unique across space and time, but reveals when and where it was created. UUID v4: Generated entirely from random numbers — no timestamp or hardware info embedded. The most commonly used version for privacy and simplicity. UUID v7: Combines a Unix timestamp prefix with random bytes, producing time-sortable IDs that work well as database primary keys without the indexing fragmentation that random UUIDs cause.

Frequently Asked Questions

What is UUID?

UUID (Universally Unique Identifier) is a 128-bit identifier formatted as a 36-character string (8-4-4-4-12). Used for unique IDs in databases, APIs, and software.

What's the difference between UUID versions?

UUID v1 uses timestamp and machine node ID. UUID v4 uses cryptographically random numbers (most common). UUID v7 uses Unix timestamp for better sorting performance.

Can I generate multiple UUIDs at once?

Yes, generate from 1 to 100 UUIDs in a single click. Useful for batch operations and testing.
