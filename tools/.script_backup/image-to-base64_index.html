What is a Base64 Data URI?

Data URI Format

A data URI embeds file content directly in HTML/CSS: data:[mimetype];base64,[data]. No HTTP request needed — the image is inline.

When to Use

Small icons, email templates, CSS backgrounds, offline apps, and JSON APIs where you need to pass images as strings.

Size Overhead

Base64 increases file size by ~33%. A 100 KB image becomes ~133 KB as a Base64 string. Use for images under 20 KB for best performance.

Browser Support

Data URIs are supported in all modern browsers (Chrome, Firefox, Safari, Edge) with no file size limit in modern engines.

Common Use Cases

HTML img tag

<img src="data:image/png;base64,...">

CSS background

background-image: url("data:image/png;base64,...");
