Frequently Asked Questions

What is an IP address?
An IP (Internet Protocol) address is a unique numeric label assigned to every device on a network. Your public IP is assigned by your ISP and is visible to websites you visit. Your private IP is used within your home or office network.
What is the difference between IPv4 and IPv6?
IPv4 uses 32-bit addresses (e.g. 203.0.113.45), allowing about 4.3 billion unique addresses. IPv6 uses 128-bit addresses (e.g. 2001:0db8::1), supporting a virtually unlimited number of devices — necessary as the internet continues to grow.
Can websites see my IP address?
Yes. Every time you visit a website, your browser sends your public IP address as part of the HTTP request. Using a VPN or proxy changes the IP address that websites see.
Is my IP address location accurate?
The city-level location shown is based on IP geolocation databases, which are accurate to within 25–75 miles for most users. ISPs often assign IP ranges to their headquarters city, not your exact location.

An IP address lookup tool reveals the geographic location, ISP, and other details associated with any IPv4 or IPv6 address — useful for network troubleshooting and security research.
