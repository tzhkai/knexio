Frequently Asked Questions

How do I format a number as USD currency?
Select USD from the currency dropdown, choose the en-US locale, and set decimal places to 2. The formatter uses the browser's Intl.NumberFormat API to produce standard output like $1,234,567.89.
What is the difference between en-US and de-DE number formatting?
In en-US, the thousands separator is a comma and the decimal is a dot (1,234.56). In de-DE (German), it's reversed: dots for thousands and a comma for the decimal (1.234,56). This differs by country and locale.
Does this tool do currency conversion?
No — this tool formats numbers as currency strings. It doesn't convert values between currencies (e.g., USD to EUR). For live exchange rates, use a currency conversion tool.
