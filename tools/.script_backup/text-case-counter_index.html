Frequently Asked Questions

What counts as a "special character"?
This tool categorizes characters into: uppercase (A–Z), lowercase (a–z), digits (0–9), spaces/tabs/newlines, standard punctuation (!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~), and "other" which includes emoji, non-Latin scripts, currency symbols, and any character outside the ASCII range.
How are words counted?
Words are counted by splitting on whitespace (spaces, tabs, newlines). Consecutive spaces count as one separator. Empty lines don't add words. This matches how most text editors count words.
Why would I need to count uppercase letters?
Common uses include checking passwords for complexity requirements (at least 1 uppercase), auditing content for shouting (all caps), checking code style rules, or analyzing writing patterns and habits.
