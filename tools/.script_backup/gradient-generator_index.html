CSS Gradient Tips

Linear Gradient

linear-gradient(135deg, #4f8cff 0%, #a855f7 100%) — flows from top-left to bottom-right at 135°.

Radial Gradient

radial-gradient(circle, #22c55e 0%, #0b1220 100%) — radiates outward from center. Use ellipse for oval shapes.

Conic Gradient

conic-gradient(from 0deg, red, yellow, green) — sweeps around a center point. Great for pie charts.

Multiple Backgrounds

Stack gradients: background: linear-gradient(...), linear-gradient(...). The first listed is on top.
