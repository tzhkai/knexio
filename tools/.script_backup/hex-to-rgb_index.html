Color Formats Explained

  

    

      
HEX (#RRGGBB)

      
6-digit hexadecimal. #ff0000 = pure red. Short form: #f00. Used in HTML/CSS. Alpha variant: #RRGGBBAA (8 digits).

    

    

      
RGB (r, g, b)

      
Red, Green, Blue channels, each 0–255. rgb(255, 0, 0) = red. rgba() adds opacity 0–1. Natural for screens.

    

    

      
HSL (h, s%, l%)

      
Hue (0–360°), Saturation (0–100%), Lightness (0–100%). More intuitive for design — tweak lightness to get tints/shades easily.

    

    

      
WCAG Contrast

      
WCAG AA requires 4.5:1 for normal text, 3:1 for large text. AAA requires 7:1. Check contrast before using text on colored backgrounds.
