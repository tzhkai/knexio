Frequently Asked Questions

What are HEX, RGB, and HSL?

HEX is a hexadecimal color code (e.g., #4f8cff). RGB uses red, green, and blue values from 0-255. HSL uses hue (0-360°), saturation (0-100%), and lightness (0-100%). All three represent the same color in different formats.

How do I pick a color?

Use the HSL sliders to adjust the color visually. The hue slider changes the color, the saturation slider controls color intensity, and the lightness slider adjusts brightness. Alternatively, type a HEX code directly.

What is the color palette?

The palette shows 10 different shades of your selected color, ranging from dark (10% lightness) to light (90% lightness). Click any shade to select it instantly.

How do I copy the color code?

Click the "Copy CSS" button to copy the color code in CSS format (e.g., background-color: #4f8cff;). The code is copied to your clipboard and ready to paste into your project.

Is this color picker free to use?

Yes, this color picker is completely free. No registration or signup is required. Just open the page and start exploring colors.

Are my color choices saved or stored anywhere?

No. All color selections and conversions happen entirely in your browser. No data is sent to any server or stored anywhere.
