What is Lottie?

Lottie is an open-source animation format by Airbnb. It renders high-quality vector animations from JSON files, widely used on websites and mobile apps for smooth, scalable animations.

Where can I find Lottie animations?

Free Lottie animations are available at lottiefiles.com and lordicon.com. Search by keyword and use the JSON URL or copy the animation JSON directly.

Does this support dotLottie (.lottie) files?

Currently this player supports standard Lottie JSON format. For dotLottie support, use the official LottieFiles player or embed via the lottie-web library.

Can I use this to preview animations on mobile?

Yes. The player works on any device with a modern browser — desktop, tablet, and mobile — so you can verify animations anywhere.
