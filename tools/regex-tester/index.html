Free Online Regex Tester

Test and debug regular expressions with instant results. Supports JavaScript regex syntax with flags for case sensitivity, multiline mode, and global matching.

How It Works

Enter your regex pattern and test text. The tool uses JavaScript's RegExp engine to find matches. Flags modify behavior: 'i' for case insensitivity, 'm' for multiline mode (^$ match start/end of lines), and 'g' to find all matches. Results display match positions, matched text, and captured groups.
