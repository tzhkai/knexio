Frequently Asked Questions

What is WCAG?

Web Content Accessibility Guidelines. AA requires 4.5:1 ratio for normal text, AAA requires 7:1.

What ratio do I need?

WCAG AA (minimum): 4.5:1 for normal text, 3:1 for large text. AAA (enhanced): 7:1 for normal text.
