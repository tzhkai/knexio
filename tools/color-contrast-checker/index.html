Tips for Checking Color Contrast

Get accurate WCAG compliance results:

  • Check Both AA and AAA: AA (4.5:1) is the legal minimum for most sites. AAA (7:1) is ideal for readability but not always required.
  • Large Text Has Lower Bars: Text 18.66px+ bold or 24px+ regular only needs 3:1 for AA. Headings often fall into this category.
  • Test on Real Backgrounds: A gradient or image background can produce wildly different effective contrast — test with the actual background your text sits on.
  • Font Weight Matters: Thin fonts (300 weight) are harder to read than bold at the same contrast ratio. If using light weights, aim higher than the minimum.

When to Check Contrast

You should verify color contrast anytime you're making design decisions that affect text legibility:

  • Before launching a new page or component — catch accessibility issues before they ship.
  • When updating brand colors — a new palette might look great but fail WCAG on certain backgrounds.
  • For any text that overlays images — semi-transparent overlays and image backgrounds are notorious contrast traps.
  • During design handoff — give developers exact color pairs with passing ratios to avoid back-and-forth.

Frequently Asked Questions

What is WCAG?

Web Content Accessibility Guidelines. AA requires 4.5:1 ratio for normal text, AAA requires 7:1.

What ratio do I need?

WCAG AA (minimum): 4.5:1 for normal text, 3:1 for large text. AAA (enhanced): 7:1 for normal text.
