How to Use

Enter the string you want to encode or decode. Select the operation using the buttons. Use the Copy button to grab the output for use in your browser or code.

How It Works

A URL encoder converts special characters (spaces, &, =, etc.) into percent-encoded format safe for use in URLs. A URL decoder reverses this process, converting %XX codes back to original characters.
